## User events / beasmenu

### beasmenu(`usereventbeasmenu.htm`)

可用的函式如下:

| userfunction | 說明 |
|---|---|
| start | 插入額外的選單項目(僅限 beas2009 Menu) |
| poststart | 在 SAP B1 Menu 內插入選單項目 |
| initmenu | 在此函式中可以定義選單類型以及是否完整載入(complete load) |
| menu[id] | 攔截所有 SAP menu id |

### start(`ue_beasmenu_start.htm`)

插入額外的選單項目(僅限 beas2009 Menu)。

在此可以操作物件 bmenu(bmenu)。

為此,在專案資料夾(project folder)中建立檔案 beasmenu.src,並定義函式 start:

```
// under Materialwirtschaft (materials management)
// a menu "hello world" when starting the message "hello world" is displayed
file beasmenu.src
function start
bmenu=add=bereich=mw,name=hello world,befehl=meldung=hello world
end function
```

更多資訊請見 bmenu。

```
// under Work order (production)
// Menu "my functions" with submenu "hello world"
file beasmenu.src
function start
bmenu=add=bereich=mw,name=my functions,child=1,stufe=2
bmenu=add=bereich=mw,name=hello world,stufe=3,befehl=meldung=hello world
end function
```

### poststart(`ue_beasmenu_poststart.htm`)

在 SAP B1 Menu 內插入選單項目。

若您要在 SBO 環境中加入更多選單,請使用

```
function poststart
end function
```

因為寫在「start」中的項目不會被考慮。

**範例**(標準解決方案的一部分):在 SAP HELP AREA 加入選單項目

```
function poststart
beasgui=addmenu=parent=help<tab>menu_id=beash1002<tab>caption=Über Beas...<tab>command=beasgui=info<tab>bitmap=mbeaslogo.bmp
beasgui=addmenu=parent=290<tab>menu_id=beash0006<tab>caption=Beas Dokumentation<tab>command=system=helponline=topic=main.html<tab>bitmap=mbeaslogo.bmp
beasgui=addmenu=parent=290<tab>menu_id=beash0006<tab>caption=Beas Script Dokumentation<tab>command=system=helponline=topic=script/main.html<tab>bitmap=mbeaslogo.bmp
beasgui=addmenu=parent=290<tab>menu_id=beash1009<tab>caption=Beas Activity Log<tab>command=tools=link2url=http://www.beascloud.com/beasweb/tfsActivityLog.php<tab>bitmap=mbeaslogo.bmp
beasgui=addmenu=parent=290<tab>menu_id=beash0008<tab>caption=Boyum-IT Homepage<tab>command=tools=link2url=www.boyum-it.com<tab>bitmap=mbeaslogo.bmp
end function
```

### initmenu(`ue_beasmenu_initmenu.htm`)

在此函式中可以定義選單類型以及是否完整載入(complete load)。

可設定以下變數:

- e_menu = 定義選單
  - 0 = beas 2009
  - 1 = standard
  - 2 = Experte
- e_completeload =
  - 1 = 載入所有項目(load all entries)
  - 0 = 只載入有授權(licensed)的項目

**範例**:對使用者「manager」使用 beas2009-Menu

```
function initmenu
if <currentuser> = manager then
   setvar=e_menu=0
end if
end function
```

(原文頁面無 Variable/Read/Write 表格。)

### stopbeasgui(`ue_beasmenu_stopbaesgui.htm`)

Beas 在 SAP 內被停止(Beas is stopped inside SAP)。

### menu[id](`ue_beasmenu_menuid.htm`)

您可以攔截 SAP 中所有的選單點擊(Menu clicks)。

```
// Catch Menu Id 4361 (Dispositionsassitant) overwrite
function menu4361
// Cancel standard function
setvar=value=-1
end function
```

```
// Catch Menu Id 4361 (Dispositionsassitant) - don't overwrite
function menu4361
// Don't cancel standard process
setvar=value=1
end function
```

(依範例程式中的註解:setvar=value=-1 為取消標準功能(Cancel standard function);setvar=value=1 為不取消標準流程。)


## User events / aps

### aps(`usereventaps.htm`)

可用的事件:

| Events | 說明 |
|---|---|
| StartCalculation | 在 APS List 中開始計算 |
| StartWorkorderPosition | 工單位置(work order position)的計算開始 |
| StartWorkorderPositionStep | 工單位置 - 步驟(Step)開始 |
| (<<) StartCalcRoutingPositionBackward | 途程位置(Routing Position)逆推計算(Backward calculation)開始 |
| (<<) MiddleCalcRoutingPositionBackward | 中間事件(Middle Event) |
| (<<) EndCalcRoutingPositionBackward | 途程位置逆推計算結束 |
| (>>) StartCalcRoutingPositionForward | 途程位置順推計算(Forward calculation)開始 |
| (>>) MiddleCalcRoutingPositionForward | 中間事件(Middle Event) |
| (>>) EndCalcRoutingPositionForward | 結束(End) |
| CalcRoutingOverlapping | 在順推計算中計算重疊(overlapping) |
| EndWorkorderPositionStep | 工單位置 - 步驟結束 |
| EndWorkorderPosition | 工單位置的計算結束 |
| EndCalculation | 在 APS List 中計算結束 |

自行計算時需要的資料表(Tables needed for own calculations):

| Table | 說明 |
|---|---|
| BEAS_RESOURCE_CALENDAR | 資源行事曆(Resource calendar) |
| BEAS_RESOURCEN | 已預留時間(Reserved times) |

| e_DocEntry | ✔ |  | 工單文件號碼(Work order document number) |
| e_LineNumber | ✔ |  | 工單位置號碼(Work order position number) |

| e_RoutingSplitt | ✔ | ✔ | 允許分割時間(Allow to splitt times):"true" 或 "false" |
| e_FixLoggedIn | ✔ | ✔ | 若工人目前正在處理,將途程位置(routing positions)固定在目前日期/時間:"true" 或 "false" |

| e_Simulation | ✔ | ✔ | 只做模擬計算:不將結果儲存到時間預留表(time reservation table)。"true" 或 "false" |

| e_TransitionTime | ✔ | ✔ | Transition Time 百分比,例如 "50" 代表 50% |
| e_OverLoading | ✔ | ✔ | 超載(Overloading)百分比 |
| e_ExecuteRule | ✔ | ✔ | 定義執行規則(execute rule):<br>1 = 計算的結束日期 > 工單交貨日期(Calculate end date > work order delivery date)<br>2 = 計算的開始日期 < 工單開始日期(Calculate start date < work order start date) |

(原文未說明取消此步驟的具體方式。)

僅限逆推計算(Only Backward Calculation)。

時間線(Time line)是閒置時間(idle time)的結束(The Time line is end of idle time)。

| 變數 | 讀 | 寫 | 說明 |

| e_MethodStep | ✔ |  | 在 Method 中可以定義多個步驟(step),此為目前步驟。第一步為 1 |
| e_DocEntry | ✔ |  | 工單文件號碼(Work order document number) |
| e_LineNumber | ✔ |  | 工單位置號碼(Work order position number) |
| e_LineNumber2 | ✔ |  | 途程位置(Routing Position) |
| e_BaseDocEntry | ✔ |  | 基礎文件,例如銷售訂單(Sales order)。僅在 MRP 中 |
| e_BaseLineNumber | ✔ |  | 基礎文件行(Base document line) |
| e_ItemCode | ✔ |  | 計算的料號(Calculated Item Code) |
| e_Quantity | ✔ |  | 計算的數量(Calculated Quantity) |
| e_CheckReservedTime | ✔ |  | 檢查已預留時間(Check reserved times) |
| e_RoutingSplitt | ✔ |  | 允許途程分割(Allow Routing Split)true/false |
| e_Simulation | ✔ |  | 模擬(Simulation)true/false |
| e_CalcSaveType | ✔ |  | 儲存類型(Save type),子表:<br>(空白) = Normal<br>S = Simulation:不儲存時間預留(Don't save time reservation)<br>I = Simulation:什麼都不儲存(Save nothing)<br>R = 針對替代資源(alternative resource)計算,並檢查時間預留(Time reservations)<br>P = Planning:儲存所有結果 |

**NOTE(注意):**

- 系統不會檢查這些變更。若您變更任何參數,您必須自行檢查/計算所有其他參數。
- 系統會將變更儲存到工單途程位置(Work order routing position),但這**不會**影響時間預留表 BEAS_RESOURCEN!

⚠ 原文疑似不一致:本頁(Start 事件)對執行時機的描述「after the calculation of this position and after creating the time reservation table」與 MiddleCalcRoutingPositionBackward 頁完全相同。

⚠ 原文疑似不一致:本頁開頭說「The Time line is end of idle time」,但 e_TimeLine 說明中的 Note 說「The time line is between transit and idle time」。

### GetBatchNumber(`ue_stockmanagement_getbatchnumber.htm`)

定義下一個批號(Batch Number)。

範例:Manual receipt、Goods Receipt Po 等。

在變數 e_DistNumber 中定義新的批號。若未定義,系統使用 Congifuration wizard 的設定。

| 變數 | 讀 | 寫 | 說明 |

**Example 1**

```
// DistNumber = today (yyyy/mm/dd) + "-" + new counter for every day
// Example: 20200501-0001, 20200501-0002, 20200501-0003 ...
function GetBatchNumber
select coalesce(max(substring("DistNumber",10,4)),0) into myCounter from "OBTN" where left("DistNumber",9) = '<today,yyyymmdd>-'
setvar=myCounter=%numadd(myCounter,1)
setvar=myCounter=000<myCounter,#0>
setvar=e_DistNumber=<today,yyyymmdd>-<myCounter,right 4>
end function 
```

**Example 2**

```
// Use B05C as Prefix + own Counter with 5 digits
// All items with MaterialGroup = "ZPT" has own counter
function GetBatchNumber
// define instance from beas Service Layer
instance bsl boy_b
// Read Material Group from item
boy_b.get=Item(<e_itemcode,bsl>)/MaterialGroupId/$value
// if Material Group is ZPT then read Counter G otherwise C
if <boy_b.ret_value> = "ZPT" then
  setvar=boy_counter=G
else
  setvar=boy_counter=C
end if
// new serial Number is B05C + Counter with 5 digits
setvar=boy_counter=00000<system.counter.boy_counter_[boy_counter]>
setvar=e_DistNumber=B05C<boy_counter,right 5>
return success
end function
```

**Example 3:**

若物料群組(material group)= 20,則手動詢問序號(serial number)。

```
function GetSerialNumber
instance bsl boy_b

boy_b.get=Item(<e_itemcode,bsl>)/MaterialGroupId/$value
// if Material Group is ZPT then read Counter G otherwise C
if <boy_b.ret_value> = "20" then
  input=SerialNumber=e_DistNumber=<e_DistNumber>
  return true
end if
 
// for all other use a item based counter
select coalesce(max(substring("DistNumber",10,4)),0) into myCounter from "OBTN" where left("DistNumber",9) = '<today,yyyymmdd>-'

// ******* Event GetSerialNumber ********

function GetSerialNumber

setvar=e_DocEntry=000000<e_DocEntry>

  - Bill of Material Issue

function print
if <e_bild1> <> "" then

  // the action "print" is directly 
  // passed-on to the application.

if <e_bild2> <> "" then
  tools=shell=<e_tree><e_bild2>=print
end if
if <e_bild3> <> "" then
  tools=shell=<e_tree><e_bild3>=print

end function
```
