## SAP UI-API

### SAP UI-API
（`sap-ui-api.htm`）

**使用 SAP Business One SDK - User Interface API**

SAP Business One UI API 透過一組功能完整的使用者介面,提供對 SAP Business One 的程式化介面。

透過 BeasScript 可以使用 UI-API。

**如何插入您自訂的功能:**

1. 開啟除錯視窗(Level 1)
2. 開啟 SAP 表單(SAP Form)
3. 在除錯視窗中可以看到 SAP 觸發的所有事件。

> **NOTE:** 不要使用 windowevents。它僅為相容性而保留。請改用 global function。

在 global function 上按兩下,系統會開啟一個 script 視窗,您可以直接在此插入程式碼。

要新增/變更元素,請使用事件 `form_clicked()`。

本章子頁面:BS Form、BS Item、BS Create objects、BS Right Click。

### BS Item
（`bs-item.htm`）

SAP Business One 表單的項目屬性(Item-Properties)。

語法:

```
item=itemuid=property...
```

| 屬性(原文) | 說明 | 適用物件 |
|---|---|---|
| `row` | 讀/寫目前列(Current Row) | 僅限 Grid,從 1 開始 |
| `rowcount` (or `maxrow`) | Grid 的列數 | Grid |
| `getrow` | Grid 的目前列 | Grid |
| `click` | 點擊該物件 | all objects(所有物件) |
| `enabled=false/true` | 設定 Enable 為 true/false,或於 "value" 取得其狀態 | all objects |
| `visible=false/tue` | 設定 Visible 為 true/false,或於 "value" 取得其狀態 | all objects |
| `caption or text=<Text>` | 設定標題(Caption) | Button |
| `description` | 設定物件的描述(Description) | all objects |
| `left` | 設定或讀取 left 屬性 | all objects |
| `top` | 設定或讀取 top 屬性 | all objects |
| `height` | 設定或讀取 height 屬性 | all objects |
| `width` | 設定或讀取 width 屬性 | all objects |
| `active=false/true` | 設定或讀取 active 屬性 | Edit-Object |
| `value` (or blank) | 設定或讀取 value 屬性 | Edit-Object, TextEdit, Combobox, Checkbox |
| `blank` | 將欄位設為空值 | Edit-Object, TextEdit, Combobox, Checkbox |
| `string` | 設定或讀取 string 屬性 | Edit-Object |
| `valon` | 傳回或設定一個字串,指定該項目「未被選取」時的資料來源值 | checkbox, Optionbtn |
| `valoff` | 傳回或設定一個字串,指定該項目「被選取」時的資料來源值 | checkbox, Optionbtn |
| `row=[x]=col=y` | Grid 物件:物件的列(Row)與欄(Col)。Row 非必要;未指定時使用目前列 | (原文空白) |
| `setcellfocus=row=col` | 將焦點設到 matrix 的特定儲存格。row 與 col 為必要 | (原文空白) |
| `backcolor` | 設定背景色。值為以 long 表示的 RGB 值。可使用標準 Visual Basic 色彩,例如 vbBlue 與 vbYellow。一般 RGB 色彩的有效範圍為 0 到 16,777,215(&HFFFFFF)。 | (原文空白) |
| `forecolor` | 設定欄位的前景色(ForeColor)。值為以 long 表示的 RGB 值。可使用標準 Visual Basic 色彩,例如 vbBlue 與 vbYellow。一般 RGB 色彩的有效範圍為 0 到 16,777,215(&HFFFFFF)。 | (原文空白) |

(註:原文有拼寫錯誤 `visible=false/tue`、`Oject`、`cel`;其中部分儲存格已翻成中文,未逐字照錄。)

**Attention(注意)**

只能設定「可見的」欄位,否則會出現錯誤。可以用 `setvar=sys_disableerrormessage=true` 停用錯誤訊息。
發生錯誤時,變數 `sys_itemsetvalue` 會被設為 -1。

**Examples(範例):**

```
setvar=myVar=<item 10>
setvar=myVar=<item 10=value>
messagebox=<item 10=value>
item=10=value=Hello
item=1=enabled=false
item=mybutton=caption=NewSave
```

**Matrix:**

```
messagebox=X-Pos: <item 38=x>
messagebox=Item in current Row: <item 38=col=1>, Rowcount: <item 38=rowcount>, Visible Rows: <item 38=visualrowcount>
item=38=col=1=ART01
item=38=row=3=col=U_MyField=value=ART01
```

**檢查欄位是否有效(Check valid field):**

```
setvar=sys_itemsetvalue=0
setvar=sys_disableerrormessage=true
item.38.column.U_myfield.value=hello world
if <sys_itemsetvalue> = -1 then
  messagebox=error$Please activate field MYFIELD in SAP Form settings.
  return failure
end if
```

```
for=loop=1=<item.38.rowcount>
  messagebox=<item=38=row=[loop]=col=1=value>
next
```

### BS Create objects
（`bs-create-objects.htm`）

建立物件,包括圖片(images)、按鈕(buttons)、文字(text)。

更多資訊請參閱 `create`。

範例:在按鈕「item 2」的右側建立一個按鈕

```
setvar=l_xpos=<item=2=x>

create button=name=mybutton,text=<mybutton>,x=<l_xpos>,y=<l_ypos>,width=<l_width>,height=<l_height>
end event
```

### BS Right Click
（`bs-right-click.htm`）

在 SAP 表單的右鍵選單中插入一個項目。

```
beasgui=rightclickmenu=type=caption=uid=[image=[position=[enabled=[checked=[command, if not windowevent...]]]]]
```

- 僅適用於 SAP 表單(sap-Forms)
- 此函式只能在 `windowevent prerightclick` 中呼叫

| Property | 說明 |
|---|---|
| `type` | 1 = 一般項目(normal entry) |
| `caption` | 選單中的文字訊息。例:`<translate:My Menu Entry>` |
| `uid` | 識別碼(物件名稱,objectname) |
| `image` | 圖片,需完整路徑,例:`<global:system_home>bmp\project_red.png` |
| `position` | 在選單清單中的位置 |
| `enabled` | boolean —— 設定啟用/停用,例 true、false |
| `checked` | boolean,設定 check 屬性 |
| `command` | 直接設定指令;但也可以改用 windowevent 處理 |

範例請參閱 Create_Right_Click_Entry。

⚠ 原文疑似不一致:本頁規定只能在 `windowevent prerightclick` 中呼叫,但 SAP UI-API 頁的 NOTE 指示不要使用 windowevents、改用 global function。

### addon connector
（`addonconnector.htm`）

透過 addon connector,可以把您自己的 addon 連接到 Beas。

**範例情境:**
為 SAP Business One 建立一個 AddOn,並使用 SAP UI 介面。

**問題:**

- 此介面不允許其他已連線的 AddOn 與您的 AddOn 溝通。
- Beas 使用自己的視窗,add-on 無法用 SAP UI 介面檢查 Beas 事件或操作 Beas 前端。

(原文此處有一張示意圖 `embim1.jpg`。)

window event connector 在 add-on 與 Beas 之間建立雙向介面。
不需要額外工具或物件,可使用 Windows 標準系統。

透過此 connector 可以操作所有 Beas 視窗屬性,並可在應用程式中執行 BeasScript。
例如可建立按鈕、按鈕上的功能、工單(work orders)、時間回報(time receipt)以及更多。

要理解此概念,請下載範例(原文連結:`http://beascloud.com/download/addon/addonconnector/beasAddOnConnectorExample.zip`)。

(原文此處有一張圖 `windoweventconnector2.jpg`。)

**使用 Test WindowEvent Connector:**

1. Beas 只能啟動一次。
2. 下載並解壓縮範例,執行 `beasAddonConnectorExample.exe`。
3. 按 Connect。
4. 在左側插入一段 BeasScript。

   **Example** —— 測試 WindowEvent Connector 的範例:

   ```
   // create a variable, make a loop and add number 1-10 in brackets
   setvar=ls_test=
   for ll_loop=1 to 10
     addvar=ls_test=(<ll_loop>)
   next
   app=external=B1UP=Return to Client: <ls_test>
   ```

5. 停用「Return Result」。它只會傳回 1 或 0,此處不需要。
6. 按「Execute Script」。
   結果會顯示出來。
8. 按「Disconnect」。

⚠ 原文疑似不一致:步驟編號由 6 直接跳到 8,沒有步驟 7。

(原文此處有 YouTube 影片連結「Addon connector」:`https://youtu.be/qPJkZ6BPZbI`。)

Beas 也可以與 AddOn 溝通:

```
app=external=<YourAddOnName>=<return text>
```

把這行直接插入 Beas,可在發生特殊事件時通知 add-on;或者您也可以把這些指令送到 Beas。請見第一個範例:

#### Example: Button in a form(表單中的按鈕)

要插入按鈕,請使用 form loaded 事件,用該函式插入按鈕。

1. 您的 AddOn 名稱:MyAddOn

   a. 在表單中插入一個您想送給 AddOn 的事件。
   開啟 Customizing editor 並插入以下 script:

   ```
   global function form_loaded
   app=external=MyExample=ResourceFormLoaded
   end global
   ```

   b. 在 AddOn 端檢查事件。若收到 "ResourceFormLoaded" 字串,即可送出以下 script 建立按鈕:

   ```
   // Create the Button
   create=button=text=MyButton,name=mybutton,position=0
   // Create an Event Call, if use click on this Button
   global function dw_master_item_button_mybutton_click 
   app=external=MyExample=ResourceFormButtonClicked
   end global
   ```

   若使用者點擊此按鈕,AddOn 會收到 "ResourceFormButtonClicked" 字串。

2. 執行該函式。

⚠ 原文疑似不一致:步驟 1 說 AddOn 名稱為 `MyAddOn`,但範例 script 中送出的對象是 `app=external=MyExample=...`。
⚠ 原文疑似不一致:此處用 `create=button=...`(等號),而 BS Create objects 頁與下一個範例使用 `create button=...`(空白)。

#### Example: Create a Button in a Beas form to fire a functionality in external Add-on(在 Beas 表單建立按鈕以觸發外部 Add-on 的功能)

本範例將在 Beas 視窗中建立一個按鈕(使用簡單的 BeasScript),此按鈕會送訊息給已連線的外部 Add-On,並執行外部功能。

1. 開啟要加入按鈕的畫面(例如 Operation Catalog 畫面),進入「Extension for clients」選項。
2. 加入以下程式碼,以便從 Beas 送訊息到外部 App:

   ```
   windowevent open
       create button=name=sendmessage,text=Send Message To My Addon
   end event

   windowevent click sendmessage
      app=external=MyAddOn=ID_001:Message from Beas to External AddOn[execute]
   end event
   ```

   "MyAddOn" --> 是您在連線到 Beas 的指令中所註冊的外部 Add-on 名稱(`app=external=register=handle=XXX<tab>name=MyAddOn<tab>subscribe=Y`)。

3. 接著要修改您的 "WndProc" 函式以捕捉此訊息:

   ```
   protected override void WndProc(ref Message m)
   {
       base.WndProc(ref m);
       if (m.Msg == 1025)
       {
           is_receipt += char.ConvertFromUtf32(m.WParam.ToInt32());
           is_receipt = is_receipt.ToLower();
           if (is_receipt.Length >= 9)
           {
               string strcheck = is_receipt.Substring(is_receipt.Length - 9);
               if (strcheck == "[execute]")
               {
                   string strcommand = is_receipt.Substring(0, is_receipt.Length - 9);
                   if (strcommand.StartsWith("welcome"))
                   {
                       m_strMsg = "Beas is connected";
                   }
                   else if(strcommand.StartsWith("id_001"))
                   {
                       //We cannot execute SAP commands directly because this event is fired by "BEAS Addon" and this addon is executed in a different
                       //Thread than SAP, if you want to send information to SAP then easy way is throught a "Timer" (There are many other options).
                       //For this example I save my message in a temp variable and the timer will send the message to SAP.
                       m_strMsg = strcommand;
                   }
                   is_receipt = "";
               }
           }
       }
   }
   ```

4. 必須理解:當您從 Beas AddOn 收到事件時,此應用程式的 context 與 SAP UI 的 context 不同,也就是兩個應用程式在不同的執行緒(thread)中執行。若您收到 beas 的訊息後直接修改 SAP 的 UI,會收到如下錯誤訊息:

   ```
   System.Runtime.InteropServices.COMException: 'An outgoing call cannot be made since the application is dispatching an input-synchronous call. (Exception from HRESULT: 0x8001010D (RPC_E_CANTCALLOUT_ININPUTSYNCCALL))'
   ```

   要避免這個典型問題,必須在「建立 SAP UI 連線的同一個執行緒」中更新 UI 物件。簡單的做法是使用 "Timer":先把訊息存在一個暫存字串變數中,再於所建立 timer 的 "Timer_Tick" 事件中處理該訊息。

5. 修改您的表單,加入一個 Timer 並實作 Timer Tick 事件:

   ```
   private void timer1_Tick(object sender, EventArgs e)
   {
       if (m_strMsg != "")
       {
           //m_sbo.SBO_Application.StatusBar.SetText(m_strMsg, SAPbouiCOM.BoMessageTime.bmt_Short, SAPbouiCOM.BoStatusBarMessageType.smt_Success);
           m_sbo.SBO_Application.MessageBox(m_strMsg, 1, "Ok", "", "");
           m_strMsg = "";
       }
   }
   ```

#### Workflow to connect(連線流程)

SAP 可以被啟動多次,相對地每個 Add-On 也會被啟動多次。請確保只與「同一個 session 中啟用的」Add-On 溝通。

- 透過 SAP-SDK 的 `application.appid` 屬性判斷 session 編號。
  使用 user32.dll 的 `"FindWindowExA( ulong hParent, ulong hChildAfter, String lpszClass, String lpszWindow )"` 指令。
  若 Beas 不經 SAP 啟動,視窗標題為 `"beaswindow:single"`。
  **Attention:** 這只在 beas 只啟動一次時有效。
- Event from beas listining and your window:`1025`。
  請參閱 WndProc 函式。
- 送出註冊字串給 Beas:

  ```
  SendMessageToBeas(m_hwndBeas, false, "app=external=register=handle=" + this.Handle.ToString() + "<tab>name=B1UP<tab>subscribe=Y");
  ```

- `Name` = 您的 Add-On 名稱
  `subscribe=0/1/Y/2/ALL` = 定義您會從 beas 收到什麼
  `handle` = 您 AddOn 的視窗 handle
  Beas 會回傳 `"welcome to beas (YourAddOnName)"`。
- 透過 `SendMessageToBeas` 指令,任何 beasscript 指令都可以送到 beas。

**Subscribe Definition(Subscribe 定義)**

| Subscribe | 說明 |
|---|---|
| `0` | Beas 不回傳任何值,只能送出指令。 |
| `1` or `Y` | Beas 回傳一個指令:-1 = failure,0 = no action,1 = ok。例:`subscribe=1`。此雙向通訊需要 Beas 取得您 add-on 的 handle id。 |
| `2` or `ALL` | Beas 會把每一個視窗事件送給您的 add-on。此雙向通訊需要 Beas 取得您 add-on 的 handle id。 |

#### Structure of a command(指令結構)

**回傳一個值**(例如某欄位的值):

```
"[handle=<your windowhandle>]itemcode=<itemcode>/itemname=<itemname>[executevalue]"
```

- `[handle=x]` 定義 Beas 要把結果送往哪個視窗 handle。
- `[executevalue]`:Beas 只針對目前作用中視窗(current active window)的結果送出該指令。
- Beas 會替換所有 placeholder。
  例:在 item 視窗中,品號 "sofa"、描述 "red sofa" 時,此 script 的結果為:`itemcode=sofa/itemname=red sofa`

**執行 beas 指令:**

- `"your beas script[execute]"` —— 在 Beas 系統視窗(systemwindow)中執行 script
- `"your beas script[executew]"` —— 在目前視窗中執行 script
- `"[handle=x]your beas script[execute]` —— 執行 script,並回傳值(-1=failure, 0=no action, 1=ok)

更簡單的方法是使用此指令:

```
private void SendMessageToBeas(int hwndBeas, Boolean bActivewindow, string strmessage, Boolean bReturnResult)
```

可用參數定義執行的類型。

⚠ 原文疑似不一致:此處說明的結尾標記為 `[executevalue]`,但下方 C# 範例 `GetValueFromBeas` 實際送出的是 `[execvalue]`。
⚠ 原文疑似不一致:`SendMessageToBeas` 的宣告有 4 個參數(含 `bReturnResult`),但註冊/取消註冊的呼叫範例只傳 3 個參數。
⚠ 原文疑似不一致:連線流程說使用 `FindWindowExA(...)`,但 C# 範例使用的是 `FindWindow`;另 C# 註解說連到 `"beaswindow:appid"`,實際程式碼寫死為 `"beaswindow:0"`。

```
// Function to send a message to Beas. Now this function can receive result of executed operation

private void SendMessageToBeas(int hwndBeas, Boolean bActivewindow, string strmessage, Boolean bReturnResult)
{
   string strMessageToSend = "";
   if (bReturnResult == true)
   {
      strMessageToSend += "[handle=" + this.Handle.ToString() + "]";
   }

   strMessageToSend += strmessage;

   if (bActivewindow == true)
      strMessageToSend += "[executew]";
   else
      strMessageToSend += "[execute]";

   //We have to send word by word
```

### PSR-File
（`referencepsr-file.htm`）

PSR 檔是由 PowerBuilder、InfoMaker 或 DataWindow Designer 建立、副檔名為 PSR 的特殊檔案。

PSR 檔包含一個 DataWindow 定義(source 與 object),以及建立該 PSR 檔當時 DataWindow 物件中所含的資料。

**從 Beas 的角度看 PSR 檔**

所有 Beas 表單都使用 PSR 檔。開啟一個視窗,就是開啟一個 PSR 檔。Beas 使用標準 PSR 檔 + 擴充功能,擴充功能儲存在 PSR 檔的「Text fields」中。

載入時,Beas 會分析報表定義,並全部改成目前所定義的 skin design(外觀設計)。

在一個 Beas 表單中,同一時間最多可開啟 7 個 PSR 檔,彼此可以重疊。例:在 MRP 檢視中有不同的報表:一個 psr 檔呈現品項清單,另一個呈現各品項的需求,依此類推。

在 Beas 中,我們所說的 DataWindows 是指儲存了 PSR 檔的物件;若只處理擷取出來的資料部分,則稱為 DataStore,別名 resultSet 物件。

可用來顯示 PSR 檔的函式(範例):

- `application.openwindow`
- `window.openwindow`

處理 resultSet 的函式(範例):

- `sqlStatement.select`
- `bsl.get`

**建立您自己的 PSR 檔**

可以建立您自己的 Beas 表單／PSR 檔。為此需要 Appeon 產品 InfoMaker 或 Powerbuilder。

更多資訊請參閱「Creating windows with Powerbuilder」。

### JSON
（`referencejson.htm`）

JSON 是一種開放標準的檔案格式與資料交換格式,使用人類可讀的文字來儲存與傳輸由「屬性-值」對(attribute-value pairs)及陣列資料型別組成的資料物件。

它是非常常見的資料格式,被各式各樣的應用程式使用,例如作為 XML 系統的替代方案。

JSON 是與程式語言無關的資料格式。它源自 JavaScript,但許多現代程式語言都包含產生與解析 JSON 格式資料的程式碼。JSON 的官方網際網路媒體類型為 `application/json`。

JSON 檔名使用副檔名 `.json`。

**資料型別(Data types)**

JSON 的基本資料型別:

| Type | 說明 |
|---|---|
| Number | 有正負號的十進位數字,可包含小數部分,可使用指數 E 表示法,但不能包含 NaN 等非數字。此格式不區分整數與浮點數。JavaScript 對所有數值使用倍精度浮點格式(後來也支援 BigInt[25]),但其他實作 JSON 的語言可能以不同方式編碼數字。 |
| String | 零個或多個 Unicode 字元組成的序列。字串以雙引號界定,並支援反斜線跳脫語法。<br>Boolean:true 或 false 兩個值之一 |
| Array | 零個或多個值的有序清單,每個值可以是任何型別。陣列使用方括號表示,元素以逗號分隔。 |
| Object: | 名稱-值對的集合,其中名稱(也稱為 keys)是字串。Object 用來表示關聯陣列(associative arrays)[2],同一 object 內每個 key 都是唯一的。Object 以大括號界定,各對之間以逗號分隔,每一對內以冒號 ':' 分隔 key(名稱)與值。<br>null:空值,使用文字 null |

來源:https://en.wikipedia.org/wiki/JSON

⚠ 原文疑似不一致:表格中 Boolean 被放在 String 列的說明欄內、null 被放在 Object 列的說明欄內,未自成一列;另保留了維基百科的註腳編號 [25]、[2]。照原文呈現。

本頁未包含任何 Beas 專屬的 JSON 指令、語法或範例。

### XML
（`referencexml.htm`）

Extensible Markup Language(XML)是一種標記語言,定義一組規則,用來以人類可讀且機器可讀的格式編碼文件。全球資訊網協會(World Wide Web Consortium)1998 年的 XML 1.0 規格以及其他數個相關規格(全部都是免費的開放標準)定義了 XML。

XML 的設計目標強調簡單、通用,以及在網際網路上的可用性。它是一種文字資料格式,透過 Unicode 對各種人類語言有良好支援。雖然 XML 的設計著重於文件,但此語言被廣泛用來表示任意資料結構,例如 web services 中使用的資料結構。

有數種 schema 系統可協助定義以 XML 為基礎的語言,程式設計師也開發了許多應用程式介面(API)來協助處理 XML 資料。

來源:https://en.wikipedia.org/wiki/XML

本頁未包含任何 Beas 專屬的 XML 指令、語法或範例。

#### 日期部分(Date area)

| Character | 意義 | Example |
|---|---|---|
| `d` | 日數,無前導零 | 9 |

| `dddd` | 星期名稱 | Monday |
| `m` | 月份數字,無前導零 | 6 |
| `mm` | 月份數字,視需要補前導零 | 06 |
| `mmm` | 月份名稱縮寫 | Jun |
| `mmmm` | 月份名稱 | June |
| `yy` | 兩位數年份 | 97 |
| `yyyy` | 四位數年份 | 1997 |

**範例(Examples)**

| Format | Displays(顯示) |
|---|---|
| `[red]m/d/yy` | 1/30/98(若此為輸入欄位的格式,以紅色顯示) |

| `dd-mmmm` | 30-January |

#### 時間部分(Time Area)

| Character | 意義 |
|---|---|
| `h` | 小時,無前導零(例如 1) |
| `hh` | 小時,視需要補前導零(例如 01) |
| `m` | 分鐘,無前導零(必須接在 h 或 hh 之後) |
| `mm` | 分鐘,視需要補前導零(必須接在 h 或 hh 之後) |
| `s` | 秒,無前導零(必須接在 m 或 mm 之後) |
| `ss` | 秒,有前導零(必須接在 m 或 mm 之後) |
| `ffffff` | 微秒,無前導零。可輸入一到六個 f;每個 f 代表秒的一個小數位(必須接在 s 或 ss 之後) |
| `AM/PM` | 兩個字元的大寫縮寫(視情況為 AM 或 PM) |
| `am/pm` | 兩個字元的小寫縮寫(視情況為 am 或 pm) |
| `A/P` | 一個字元的大寫縮寫(視情況為 A 或 P) |
| `a/p` | 一個字元的小寫縮寫(視情況為 a 或 p) |

|---|---|

| `h:mm:ss` | 21:45:33 |

| `h:mm:ss:fff` | 21:45:33:234 |
