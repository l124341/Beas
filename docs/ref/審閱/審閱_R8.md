## 翻譯問題

### [誤譯] gs1_128_js.htm — Additional Info 表,AI 00
- 嚴重度:低
- 原文:「Serial Shipping Container Code (SSCC)」
- 目前中文:「系列貨櫃運送碼(SSCC)」
- 問題:「Serial」在此指「序列(編號)」,非「系列」;且 SSCC 指的是物流運送單元(箱/棧板),不限貨櫃。屬字面誤譯,不影響 AI 代碼與長度資訊。
- 建議修正:「序列貨運包裝箱代碼(SSCC)」或「運送容器序號碼(SSCC)」
