## Windows / Open a window

### Open a window

（`open-a-window.htm`）

如何開啟 Beas、B1UP 或 SAP 視窗的總覽。

- 參見 Customizing by window
- 參見 BeasScript - open window

| 指令（Command） | 說明 |
|---|---|
| `openform` | 以參數開啟視窗（簡易版本）。可用清單：<br>- Beas forms（Beas 表單；連結至 Beas window id 頁）<br>- SAP B1UP forms（SAP B1UP 表單；連結至 SAP Form Id 頁） |
| `openwindow` | 開啟一個與父視窗有關聯的子視窗。開啟視窗之前，會先儲存父視窗的內容。 |
| `opennewwindow` | 與 `openwindow` 相同，但與父視窗沒有關聯。可以關閉父視窗而不會關閉已開啟的視窗。 |
| `openchild` | 與 `openwindow` 相同，但不會儲存父視窗的內容。當你在子視窗與父視窗之間變更資訊，但不想使用 response 時使用。<br>可以將子視窗以強制回應（modal）表單方式開啟。 |

- **`beas_WorkOrder_Structure`**：Open work order Structure window（開啟工單結構視窗）。（原文此處有圖片 `custom_fert_stuktur_browse.png`）
  - 選用參數：`DocEntry,LineNumber`：只開啟此工單。

- **`beas_WorkOrder_Edit`**：Work order Edit form（工單編輯表單）。參數：DocEntry
  ```
  application.openwindow("beas_WorkOrder_Edit",6002253);
  ```
  或者，也可以用物件方式設定參數：
  ```
  application.openwindow("beas_WorkOrder_Edit",{DocEntry:6002253});
  ```
- **`beas_WorkOrderPos_List`**：List of Position from a work order（某工單的位置清單）。參數：DocEntry
  ```
  application.openwindow("beas_WorkOrderPos_List",6002253);
  ```

- **`beas_WorkOrderBOM_List`**：Work order Bill of Materials List（工單物料清單清單）。參數：DocEntry, LineNumber

- **`beas_ItemMasterData_Structur`**：Item Structure window（品項結構視窗）。
  - 參數：
    1. 開啟方式（Open by）：
       - `filter`：在下一個參數中定義自己的篩選條件
       - `filterfix`：在下一個參數中定義自己的篩選條件，且此條件無法在表單中被覆寫
       - `item`：在下一個參數中定義要開啟的品項編號，並從該品項展開結構
  - 範例：開啟品項 "FP" 的結構（原文此處有 BeasScript 圖示 `formel_bscript.png`）
    ```
     openform=beas_ItemMasterData_Structur|item|FP

### Terminal

（`terminal2.htm`）

桌面終端（Desktop Terminal）包含下列可自訂的事件：

| 事件名稱（Event name） | 說明 |
|---|---|
| `terminal_displaybuttons_before` | 此事件允許修改 `e_accessgroup` 參數，該參數決定要顯示的選單。若此參數留空，系統預設會選用該機器的預先定義設定。 |
| `terminal_displaybuttons_after` | 此事件讓使用者能進一步變更按鈕顯示邏輯，例如在畫面出現之前顯示不同的按鈕清單、移除某些按鈕，或對既有按鈕套用特定邏輯。<br>這些事件讓使用者在自訂按鈕行為、以及在所有按鈕顯示後套用動作時，有更大的彈性。 |

**範例：**

覆寫 `terminal_displaybuttons_before` 事件以顯示自訂的按鈕清單。

不從使用者設定載入按鈕定義，而是讀取「Work Station Settings Wizard」中終端設定所指定的按鈕定義：

`menu_terminal.src:`

```
windowevent terminal_displaybuttons_before
// Available Variables:
//  e_accessgroup   Todo
//
//Customization to ignore user access group and display menu defined in Work station settings.
//This script is applied only to machines "JEM_ES_DESKTOP" and "XXX" machine, but you can remove the condition and apply this for all machines
if <system.computername> = JEM-ES-DESKTOP or <system.computername> = XXX then
 setvar=e_accessgroup=
end if
//You can return false if you don't want to display any button
return true

#### Logical formulas（邏輯公式）

`<%PROGRAMNAME%>` 也允許使用如下結構的邏輯公式（⚠ 原文此處為未替換的佔位字 `<%PROGRAMNAME%>`，照錄）：

```
if ( logic , value by true , value by false)
```

例如：

```
if ( red = blue , 3.34 * x , 0 ) + (x * 2)
```

邏輯字元與函式（Logical characters and functions）：

| 運算子 | 說明 | 範例（照原文） |
|---|---|---|
| `=` | 兩個值相同 | `Price = 100` |
| `>` | 左值大於右值 | `Price > 100` |
| `<` | 左值小於右值 | `Price < 100` |
| `<>` | 左值不等於右值 | `Price <> 100` |
| `>=` | 左值大於或等於右值 | `Price >= 100` |
| `<=` | 左值小於或等於右值 | `price <= 100` |
| `NOT=` | 左值不等於右值 | `Price not = 100` |
| `LIKE` | 左值是右值的一部分 | `Name like 'C%'` |
| `IN` | 左值包含在右側清單中 | `Price in (100,200,300)` |
| `BETWEEN` | 左值在範圍內 | `Price between 1000 and 2000` |
| `NOT LIKE` | 左值不在右值中 | `Price not like 'C%'` |
| `NOT IN` | 左值不在右側清單中 | `Price not in (100,200,300)` |
| `NOT BETWEEN` | 左值不在範圍內 | `Price not between 1000 and 2000` |

LIKE 可使用萬用字元：

- `%`：任意數量的字元
- `_`：任意單一字元

範例：

- `'c%'`：符合任何以 c 開頭的字串
- `'c_'`：符合任何以 c 開頭、且後面再多一個任意字元的字串

#### Logical links with "if"（以 "if" 做邏輯連結）

條件可以用 AND 與 OR，以及 NOT AND/OR 連結：

```
if ( x = y and x = z ,1,0)
if ( x = y or x = z,1,0)
if ( x = y and not x = z,1,0)
```

**以 "case" 撰寫邏輯公式（Logical formulas with "case"）**

使用 case 可依條件回傳不同結果。

```
case ( column when value1 then result1 { when value2 then result2
    { ... } } { else resultelse } )
```

```
case (marriage_status when 'S' then 'Single' when 'M' then 'Married' else 'Unknown')
```

#### Working with characters (strings)（處理字元／字串）

字元可以被處理。

字元以 + 結合：

```
a = "Adam"
b = "Eve"
a + " " + b = "Adam Eve"
```

字串的開頭與結尾必須加以標示。

下列可作為標示符號（identifier fields）：

```
"        "Hello World"
'        'Hello World'
[.]        [Hello World]
```

若字串以另一種標示符號開頭，則可在字串中使用標示符號：

```
"[Hello] 'World'"                Result: [Hello] 'World'
```

有許多字元編輯函式：

| 函式 | 說明 | 範例（照原文） |
|---|---|---|
| `fill` | 回傳填滿的字串 | `fill("*"),3) = "***"`<br>`fill("-+"),5) = "-+-+-"` |
| `left` | 右側被截斷的字串 | `left("hello world,6)="hello "` |
| `lefttrim` | 右側被截斷且移除空白的字串 | `leftright("hello world,6)="hello"` |
| `len` | 回傳字串中的字元數 | `len("hello") = 5` |
| `lower` | 將字串中的大寫字母換成小寫字母 | `lower("Hello") = hello` |
| `match` | 檢查所使用的字元（詳見 Sybase Infomaker） | `match("A","^[A-Z]) = true` |
| `mid` | 回傳字串的指定部分 | `mid("Hello",2,2)= "al"` |
| `Pos` | 回傳指定字串在第一個字串中的位置 | `pos("Hello","l") = 3` |
| `replace` | 以字串取代另一字串中的部分 | `replace("David", 4, 2, "e") = "Dave"` |
| `right` | 左側被截斷的字串 | `right("hello world",5)=" world"` |
| `righttrim` | 左側被截斷且移除空白的字串 | `righttrim("hello world",5)="world"` |
| `space` | 回傳指定數量的空格 | `space(5)="     "` |
| `string` | 將數字、日期、字元轉換為格式化字串，並依循國際設定。 | `string(5.2344,"#,#0.00")`<br>Germany: `"5,23"`<br>USA: `5.23` |
| `trim` | 移除左右兩側的空白 | `trim(" hello ") = "hello"` |
| `upper` | 將字串中的小寫字母換成大寫字母 | `upper("Hello ") = "HELLO"` |
| `wordcap` | 將第一個字母轉為大寫，其餘轉為小寫。 | `wordcap("boston, MASSACHUSETTS")`<br>`= "Boston, Massachusetts"` |

⚠ 原文疑似不一致：
- `lefttrim` 列的範例寫成 `leftright(...)`，函式名稱不同。
- 數個範例的引號或括號不成對：`fill("*"),3)`、`fill("-+"),5)`、`left("hello world,6)`、`leftright("hello world,6)`、`match("A","^[A-Z])`。
- `mid("Hello",2,2)= "al"`：結果 "al" 並非 "Hello" 的子字串。
- `right("hello world",5)=" world"`：參數為 5，結果卻是含前導空白的 6 個字元。
