@doctype = your document-type (String)

（@doctype＝你的單據類型（字串）；@docentry＝你的單據項目（字串）；@linenum＝你的單據行（字串）；@batchnum＝你的批號或序號 intrserial（字串）或空白；@bincode＝儲位代碼；@rfid 為空；@quantity＝此儲位代碼的數量；@pers_id＝目前的 beas_pers.pers_id 使用者（或空白）；@station＝目前的工作站 id（取自用戶端，而非伺服器）；@version＝你的程式目前的名稱與版本。）

```
// get Transaction and Instance from this document-line
select @transnum=oivk.transnum,@instance=oivk.instance
 from oivl  inner join oivk on oivk.transseq=oivl.transseq and layerid=0
 inner join oitm on oitm.itemcode=oivl.itemcode
 where  oivl.transtype=@doctype and oivl.createdby=@docentry and oivl.doclinenum=@linenum
// Call the BinBooking
dbo.beas_binbooking @transnum,@instance,@batchnum,@bincode,@rfid,@quantity,@pers_id,@station,@version
```

若傳回值 = 1，則一切正常，否則顯示錯誤。

**STORNO（沖銷）**

可以為儲位交易建立沖銷（Storno）。沖銷時將數量設為 < 0。

**BIN-BIN-Transaction（儲位對儲位交易）**

BIN-BIN-Transaction 沒有 SAP 單據。

Obj-Type 為 99。

BIN-BIN-Transaction 要在 beas_oinm 中插入 2 筆記錄，且 instance 編號大於 99000：

```
select @transnum=isnull(max(transnum),0)  from beas_oinm;
select @instance=isnull(max(instance),0) +1 from beas_oinm where transnum=@transnum
if @instance < 99000
   set instance=990000
```

接著在 beas_oinm 中為發料與收貨插入 2 行：

```
insert into beas_oinm (transnum,instance,transtype,beas_ref,itemcode,doclinenum,docdate,in0out1,quantity,openqty,warehouse)
  values (@transnum,@instance,99,'',@itemcode,0,getdate(),1,@quantity,@quantity,@whscode)
insert into beas_oinm (transnum,instance+1,transtype,beas_ref,itemcode,doclinenum,docdate,in0out1,quantity,openqty,warehouse)
  values (@transnum,@instance,99,'',@itemcode,0,getdate(),0,@quantity,@quantity,@whscode)
```

若為批號品項，則將批號插入 beas_oinm_batchnum（僅作為此交易的資訊）：

```
insert into beas_oinm_batchnum(transnum,instance,linenum,batchnum) values (@transnum,@instance,0,@batchnum)
insert into beas_oinm_batchnum(transnum,instance,linenum,batchnum) values (@transnum,@instance+1,1,@batchnum)
```

呼叫過帳程序：

```
dbo.beas_binbooking @transnum,@instance,@batchnum,@from-bincode,@from-rfid,@quantity,@pers_id,@station,@version
dbo.beas_binbooking @transnum,@instance +1,@batchnum,@to-bincode,@to-rfid,@quantity,@pers_id,@station,@version
```

⚠ 原文疑似不一致：文字說 instance 編號要「大於 99000」，程式碼中檢查 `if @instance < 99000` 後卻設為 `990000`（多一個 0），且寫成 `set instance=` 而非 `set @instance=`。
⚠ 原文疑似不一致：第二個 `insert into beas_oinm` 把 `instance+1` 寫在欄位清單中，而 values 中仍是 `@instance`；與後面 beas_oinm_batchnum 及 beas_binbooking 呼叫使用 `@instance+1` 的寫法不一致。
⚠ 原文疑似不一致：參數表列出 station_id，範例變數用 @station；範例另宣告 @doctype／@docentry／@linenum 用於查詢 transnum/instance，非程序參數。照原文保留。

## Database / structure of the DB.INI

### structure of the DB.INI
（`aufbau_der_db_ini.htm`）

呼叫「check database」（檢查資料庫）時，會啟動資料庫更新，以自動更新新增或變更的欄位或資料表。

此時會處理檔案 DB.INI。DB.INI 中的指令由程式解譯。

注意：不允許手動修改資料庫！

以下是 DB.INI 可用的指令：

| 指令 | 說明 | 範例（逐字保留） |
|---|---|---|
| `version=<versioninfo>` | 目前版本：67xxxyy（xxx = 版本號，yy = 建置號） | `version=6700008` |
| `versiondatum=<versiondate>` | 目前版本的日期 | `versiondatum=4.07.2005` |
| `table=<tablename>` | 檢查一個資料表 | `table=beas_mrp_planung` |
| `udt=<tablename>=<Description>=<type>` | 建立一個 SAP 資料表<br>type：Noobject, Masterdata,masterdatalines,Document, documentlines,Noobjectautoincrement<br>若要在 udt 加入 UDF，必須寫資料表名稱（不含 @ 符號）<br>不要使用前綴「beas」：`beas_color -> wrong`、`mycompany_color -> correct` | 見下方區塊 |
| `udf=<tablename>=<columnname>=<description>=<type>=<type2>=<length>` | 建立一個 SAP 欄位<br>type：Alpha,Float,Numeric,dec<br>type2（Alpha 時）：regular, adresse, telefon, text<br>type2（Float 時）：Rate,sum,Price,quantity,percent,measure<br>不要使用前綴「beas」：`beas_color -> wrong`、`mycompany_color -> correct` | `udf=OITM=beas_myField=This is my field=dec=quantity` |
| `Column=<tablename>=<columnname>=<datetype>=<description>` | 檢查一個欄位 | `column=beas_mrp_planung=bezeichnung=nchar(80)=Bezeichnung` |
| `sapcolumn=<tablename>=<columnname>=<datetpye>=<description>` | 檢查一個 SAP（原文：checks a SAP） | `sapcolumn=OJDT=u_monat=int=monat (partition in month) Nummer` |
| `sapcolumninfo=<description>` | SAP 欄位的資訊 | `sapcolumninfo=Journalbuchung` |
| `primary=<tablename>=<columname>` | 為欄位設定主鍵 | `primary=beas_mrp_planung=id` |
| `default=<tablename>=<columnname>=<value>` | 為欄位設定預設值 | `default=beas_stl=lfdnr=0` |
| `droptable=<tablename>=true/false=<columname>` | 刪除資料表：<br>true：若欄位存在則刪除<br>false：若欄位不存在則刪除<br>無條件：一律刪除 | `droptable=beas_mrp_planung=true=bezeichnung` |
| `delcolumn=<tablename>=<columname>=<datetpye>=<description>` | 刪除一個欄位 | `delcolumn=beas_mrp_planung=lfgdat_von=nchar(12)=Parameter von Lieferungsdatum` |
| `abgleich=<sql-command>` | 若有「abgleich」（比對）名稱，則執行指定的 SQL 指令 | `abgleich=delete from beas_caft_var where varedit='N'` |
| `abgleichname=<description>` | 啟用一個比對 | `abgleichname=pk_typen` |
| `meldung=<description>` | 輸出一則訊息 | （原文無範例） |
| `prozent=<value>` | 以百分比顯示進度 | （原文無範例） |
| `script=<Scriptname>` | 呼叫並解譯一個包含 BEAS-Script 的檔案 | （原文無範例） |

udt 範例（原文）：

```
udt=BEAS_TEST=Desc Table
udf=BEAS_TEST=beas_Status=Status=alpha=regular=20
```

⚠ 原文疑似不一致：udt、udf 的說明都寫「不要使用前綴 beas」（beas_color 錯誤、mycompany_color 正確），但範例本身使用 `BEAS_TEST`、`beas_Status`、`beas_myField`。
⚠ 原文疑似不一致：udt 語法為 `udt=<tablename>=<Description>=<type>`，範例 `udt=BEAS_TEST=Desc Table` 未給 type；udf 語法有 `<length>`，範例 `udf=OITM=beas_myField=This is my field=dec=quantity` 未給 length。
⚠ 原文疑似不一致：語法列寫「Column=」（大寫 C），範例寫「column=」；sapcolumn 的說明「checks a SAP」語句不完整；sapcolumn／delcolumn 語法中「datetpye」為原文錯字。
