- ⚠ **PDF 建立日期為 2022-02-21**：內容反映的是當時的資料庫結構，與目前版本可能有出入，使用前請自行核對實際資料庫。

- 整理方式：欄位名稱與原文說明逐字照抄（含德文、拼字錯誤，例如 backlfush、availabe、stinrg 都保留原樣）；「中文說明」是翻譯。PDF 欄位表除了 Description 之外，有些列在右側還有說明文字欄和值代碼欄，本文件分別以「〔附註〕」和「〔值〕」標示（這兩個標籤是整理時加上的，PDF 上沒有）。版面上折行的說明已合併為同一列。
- pdftotext 輸出中有些欄位名稱和說明黏在一起（例如 `MANUELL_PLANWERTManually Plan Value`），已依 PDF 文字座標拆開。
- 中文欄標「（照抄，原文未說明含義）」的是 PDF 只給縮寫或代號、沒有說明含義的項目，不做推測。
- 只收錄有「Column  Description」欄位表的資料表；PDF 開頭的目錄不在本區塊範圍內。
