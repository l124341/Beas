## 體例說明

- 每節括號內的「標題」是 PDF 表頭中間的藍色標題(在 PDF 中為圖片,已以人工判讀圖片取得;pdftotext 讀不到);「類別」是表頭右側的分類字樣。
- 部分表名在 PDF 表頭被排版截成兩行(如 `BEAS_RECLAMATION_CAUSERUS` / `ER`),本文件合併成一行,並與 PDF 開頭目錄的寫法核對過。
- 部分欄位名在 PDF 文字層與說明黏在一起(如 `MeasurementPersNameMeasurementPersName`),或欄位名過長被排到上一行,本文件依 PDF 頁面圖片拆開/合併,不另標註。
- PDF 欄位表有三欄:Description(短說明)、說明備註、值代碼。本文件「原文說明」欄的格式為:`短說明`;若有備註則接 `<br>備註:…`;若有值代碼則接 `<br>值:…`(多個值以「;」分隔)。備註中的版面換行已合併為空白;原文的拼字錯誤(如 Chaged、Sytem、Resevation)一律照抄。
