ue_api_routing


Contents

api_routing is a Object for Administration of Work schedule.

 

Only be used in Beas, not beasgui!

 

You can declare the object with:

declare=<mybom>=ue_api_routing

 

Methods

getbykey=<item>

load=<item>

Loads a Work schedule

load_or_new

Load a work schedule or creates a new one

new=<item>

Create a Work Schedule, or loads if already exists

addline

Add a new Row

setrow=<row>

Set the actual Row

update

Update / Save the actual Work Schedule.

resource=add

Add a Resource.

header

Aall header function for routing header

goto_pos=<pos_id>

Seeks pos in the bom-list and sets the current position to this position

if the position is not found, api_bom will return -1 in variable value

 

Example:

routing.getbykey=<routing-id>

routing.goto_pos=10

if <value> n= 1 then

 routing.description=modified description

end if

 

 

 

All Methods will return  a Variable "value" ("1=ok / 0=error" ).

Example (for insertion of routing):

declare=routing=ue_api_routing

routing=new=A001

routing=header=description=my first routing

routing=addline

routing=description=work

routing=workcenter=A001

routing=maschinetime=50

routing=update

destroy=routing

routing=addline

routing=maschinetime=50

routing=resource=addline
