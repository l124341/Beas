exportgraphicstofile(string,typ)

Export to file.

xgantt=exportgraphicstofile=file=type
 

Example: xgantt=exportgraphicstofile=C:\Temp\gantt.png=7
 
       Available values:

VMF — 0 — File will be written in the format VMF.

WMF — 1 — File will be written in the format WMF.

BMP — 2 — File will be written in the format BMP.

EPS — 3 — Deprecated

GIF — 4 — File will be written in the format GIF.

JPG — 5 — File will be written in the format JPG.

PCX — 6 — Deprecated

PNG — 7 — File will be written in the format PNG.

TIF — 8 — File will be written in the format TIF.

EMF — 9 — File will be written in the format EMF.

WMFWithEMFIncluded — 10 — File will be written in the format WMF, additionally including the format EMF.

EMFWithEMFPlusIncluded — 11 — File will be written in the format EMF, additionally including the format EMF+.

EMFPlus — 12 — File will be written in the format EMF+
