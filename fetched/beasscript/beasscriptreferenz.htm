Contents

 

Beas has the following object structure:

 

System

The program itself.

Form

The window inside the program frame.

DataWindow

The Formula. You can define up to 7 formulas (PSR Files) per window. Name is dw_1....dw_7

Item

A field (Column, Textfield, Bitmap and so on) of a Formula
