bmenu


Contents

bmenu is an object which is visible ONLY at  the menu construction and is available in beasmenu.src.

 

init

Initialize

add

Adds a Menu Item

You can specify parameters with separate lines or comma:

add=name=Hello world,befehl=meldung=Hallo World

load=<datei>

Load File

expand

Expands the current Menu Item

menubefehl xx

Menu command. see below

 

Menu parameters

bereich

Menu Group. see below under Group

stufe

Indention.

1 = Upper Area

2 = Lower Area

Remark: Handle 1 carefully... It could break following menu entry's

recht

Just visible if rech = id. see rechte.ini

bitmap

Bitmap ( only with stufe = 1)

name

Name

befehl

Command ( to be executed )

modul

Only actively if suitable module was activated

child

Set this point as Master entry with Sub entries (This point have childs)

bmenu=name=Level2,bereich=extra,child=1,level=2

bmenu=Name=Level3,bereich=extra,level=3
