header


Contents

 

You can use the header function without the bom-base function, I

If you load a BoM or create a new BoM, the header is loaded/created automatically

 

bom=header=load=<bom-id>

Load header. If not existing: create the header

bom=header=update

Update/Save the BoM

bom=header=initall

create header for all BoMs for which no header exists

bom=header=property=value
Set Property in header

 

Example:

declare=bom=ue_api_bom

bom=getbykey=A001

bom=header=description=my bom

bom=update

bom=setrelease=1
