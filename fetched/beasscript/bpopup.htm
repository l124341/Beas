bpopup

 

Dynamic Popup Menu.

You can control Bitmap, comment, name, command and Page Number

 

 

add

add a text

bpopup=add=<bitmap>=<description>=<pagenumber>=<command1^command2..>

 

or in CSV Format

bpopup=bitmap=...<tab>page=...<tab>...command=openwindow=test.psr<wintab>param=x

 

Available properties:

bitmap

the bitmap

name

title of text

if title start with "!" beas don't translate this text, otherwise beas translate the text

page

page nr

command

the script to execute

if you use openwindow, then don't use <tab> - use <wintab> in the command string

value1, value2

the value

typ

the typ

0 normal, 1 with input, 2 with input area

 

 

add a line

bpopup=add=line

bpopup=add==-=<pagenumber>

type

last entry was an entry from

0 = Normal

1 = with 1 input field

2 = with 2 input fields

bpopup=add=<bitmap>=<description>=<pagenumber>=<command1^command2..>

bpopup=typ=1

bpopup=value1=hello

 

command:

the command or function which you want to call

Line feed with Sign ^

 

Type 1+2

You can read the values in the command {value1} and {value2}

Example:

messagebox={value1}^messagebox={value2}

 

If you need the values outside of the bpopup, you must set a Variable

bmp\key.png=Insert your key=1=setvar=ls_myvalue={value1}^callmyfunction()

 

 

value1, value2

for type 1 and 2

you can set the default value for value1 and value2

bitmap=<page>=<picturename>

set the page-icon (first line)

width

set the width of popup window

bpopup=width=1200

reset

reset the menu

bpopup=reset

redraw

redraw the menu

bpopup=redraw

visible=object=true/false
set a menu entry visible / invisible

 

with this command you can make menu entries invisible in the event

 

windowevent bpopupredraw

bpopup=visible=redit=false

end event

 

In this example you make "resource group edit" invisible

You must set the object name

You can see the name of object in the debug window

addrightclickmenu

menu=addrightclickmenu=x

not part of bpopup, but is a function for the bpopup:

insert the right

 

You can declare a menu like this:

 

bpopup=reset

bpopup=add=<bitmap>=<description>=<pagenumber>=<command1^command2..>

bpopup=redraw

 

"redraw" will trigger a redraw of the menu

 

The PopMenu will be closed if:

- the cursor is moved over the first entry

- ESC

- after you made a selection with Mouse or Enter

 

Menu page will change if:

- Right mouse click on Menu

- Cursor left / right

- Ctrl+Shift

 

Example

 

bpopup=reset

// after reset you need a empty add

bpopup=add

// Key-Line with input field

bpopup=add=bmp\key.png=Insert your key=1=messagebox={value1}

bpopup=typ=1

bpopup=value1=abcdef

// second tab with command

bpopup=add=bmp\layout.png=Set layout=2=messagebox=calling function layout

// Bitmap Page 1 and 2

// add Standard-Right-Click

menu=addrightclickmenu=3

bpopup=bitmap=1=bmp\clients.png

bpopup=bitmap=2=bmp\constructionfirm.png

// Display

bpopup=width=1200

bpopup=redraw
