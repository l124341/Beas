beasfunction


Contents

Calls a predefined Beas function

 

beasfunction=[functionName]=Parameter

 

Example: Calculate APS Scenario "Standard"

 

beasfunction=CalculateAPS=Standard

 

 

List of available Beas Standard functions

Function

Parameter

Description

CalculateAPS

APSScenario-Id

Calculates the defined APS Scenario

CalculateMRP

MRP-Id

Calculates the defined MRP Scenario
