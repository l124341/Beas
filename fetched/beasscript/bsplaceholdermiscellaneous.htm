Standard functions

 

%var("variable"[,"format"[,"format"]])

return value from Variable without converting

 

setvar=ls_test="today is <today>"
messagebox=<%var("ls_test")>

 

alternative

setvar=test=%var("ls_test")

 

with format you can set string formats

Example

setvar=test=%var("ls_test","left 20","replace A B")

 

this function is faster than a normal placeholder <test>

%column([parent/child,][dw_x,] "columnname"

   [,format])

returns value of datawindow column

 
setvar=ls_test=%column("dw_1","itemname")
 
setvar=ls_test=%column("parent","dw_1","itemname")
 
setvar=ls_test=%column("itemname")
