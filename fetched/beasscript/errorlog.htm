Editing the error logs

 

For every error message a protocol entry is carried out which, however, is not stored in the Database

About these functions the protocols can be processed.

 

 

tools=errorlog=read

copied the contents of the log table in the variables error[x] and the number of messages in <errorcount>

tools=errorlog=read

setvar=ls_text=

for ll_loop = 1 to <errorcount>

 setvar=ls_text=<ls_text><cr_lf><error[ll_loop]>

next

message=<ls_text>

tools=errorlog=reset

deletes the error log
