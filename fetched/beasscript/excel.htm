object ue_excel

Example Video

 

Work with a excel-sheet in a ole-object

 

Property / Method

Description

opensheet

opens a sheet

load

loads a sheet and displays the excel-sheet

visible

makes excel-sheet visible/invisible

inplace

sets object-display in place

offsite

sets object-display to off-site

get

returns a value from an excel-sheet

excel=get=sheet=row=col

or <excel=get=sheet=row=col>

or excel=get=<sheet-variable>=<row-variable>=<col-variable>

returns in Variable <value>

 

destroy=lex
declare=lex=ue_excel
lex=opensheet=myexcelfile.xlsx
lex=visible=0
lex=inplace
   
// Get:
// lex=get=sheet=row=col
 
for ll_loop = 1 to 20
  lex=get=1=ll_loop=2
  dw_1.item.columname:[ll_loop].value=<value>
next
   
// Set:
// set=get=sheet=row=col=value
 
for loop = 1 to 20
  lex=set=1=loop=3=<dw_1.item.columname:[loop].value>
next
 
// Close
 
lex=inplace
lex=quit
destroy=lex

set

sets a value in excel-sheet

excel=set=sheet=row=col=value

close

close excel-sheet

 

to close a excel-object:

destroy=lex
declare=lex=ue_excel
lex=opensheet=myexcelfile.xlsx
lex=visible=0
lex=inplace
lex=quit
destroy=lex

quit

quit the object

save

save excel-sheet

saveas

save as the excel-sheet

disconnect, destroy

destroy the object
