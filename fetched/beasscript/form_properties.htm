closesetfocus=parent/no

 

x
Define which form should have focus after closing

 

form.closesetfocus=parent   parent form receives  the focus (default)

form.closesetfocus=no         don't set focus. Next form receives the focus

 

if you want open a new form from child form and you want to close your child form, the new form must have the focus. In this situation set form.closesetfocus=no

 

Example:

Preview form (Preview Icon)

1. Beas opens form "current form", "Report...."
2. Beas closes this form and opens the report itself

 
In this situation the form must lose the focus

 

is_closesetfocus=parent/no

reload

 

 

x
Reload the form

 

Execute the Reloading process

1. execute event "retrieve".

2. update form. if any data changed, Beas runs the complete update process

3. start resizing process

 

if you set the parameter "retrieve", Beas does not reload the dataform definition and make only the retrieve process

 

Example:

 

form.reload

 

form.reload=retrieve

 

Old syntax: retrieve, reload

type

x

x
return type / form of form

 

Return values:

report = Report form (Print preciew)
browse = browse form

structure = Structure form

edit = Edit form (1 line)
editbrowse = Editable browser form

choose = choose form

 

Beas sets this with command menu.typ=<property>

This command defines the default buttons
It is a part of settings in Ctrl+N+B

 

You can overwrite this with

form.type=...

This command don't change the default buttons.
But other functions, example check B1UP functions, check the property

 

Example

// set buttons for browse form
menu.typ=browse
// but form is a structure view
form.type=structure

 

Alias for write: form.typ

beas 9.2 PL 06, iws.is_type
