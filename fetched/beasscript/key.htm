key


Contents

key=<KeyCode>=command^command

 

Link a command to a Key.

You should not use this on Input fields with Cursor-keys.

Only in Beas-forms!

 

Example:

key=ENTER=close:ok

 

If you hit the Return key, the form will be saved and closed.

 

 

Combinations:

ALT+A                A-A

SHIFT+A        S-A

STRING+A        C-A
