ue_mrp


Contents

MRP (material resource planning) object

 

Functions

Function

Description

purchase reuqest

generates a purchase request

server

Starts all calculation which calculationflag "BERECHNENSCHALTER" is "J"

Use this only if you do not work with a large data set.

Example: object=ue_mrp=server
 

NOTE: If an MRP scenario has an error from a previous calculation, or the calculation is still running, this process will cancel the calculation of that scenario. If you want to force a re-calculation, you can execute the method "calc" instead of this one.

calc

Starts MRP calculation x

Example: Calculate MRP 1
object=ue_mrp=calc=1

calcwithnewtask

calculates MRP in a separate task

object=ue_mrp=calcwithnewtask=1

teilekonto

opens the item inventory history window

object=ue_mrp=teilekonto=A001
