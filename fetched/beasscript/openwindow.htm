openwindow, opennewwindow, openchild


Contents

With this command you can open a window.

 

Command

Description

openwindow

opens a child window in relation to the parent window. Before opening the window the content of the parent is saved.  

opennewwindow

same as openwindow, but without relation to the parent window. You can close parent window without closing the opened window

openchild

same as openwindow, but without saving the content of the parent window. Use this when you change information between child and  parent window but you do not want to use response .

openform

open a new form with very simple syntax. See openform

 

Every window is saved as a PSR file name. Same concept as HTML pages.  PSR Files are DataWindows, created with Development System "PowerBuilder".  Most windows have default Beas form names which you can use alternatively.
Most windows need parameters. The parameters are defined in a fix structure with the name str_parm. The properties are s_parm1...5 for String values, c_parm1...5 for decimal values and many more.

 

For opening the window you define the PSR file with property "dw" and with delimiter "<wintab>" you define next values, example s_parm1.

 

Syntax

openwindow=dw=<psrfile><wintab>s_parm1=<value><wintab>....

 

Example:

Open item window as new window
With Window name

openwindow=dw=beas_ItemMasterData_Edit<tab>s_parm1=RM

With PSR File name

openwindow=dw=artikel_edit.psr<tab>s_parm1=RM

With Command "openform"

openform=beas_ItemMasterData_Edit|RM

 

Note:

•You can use "<tab>" or real tab char (in beas script "~t" as delimiter. But all delimiter in one command must be the same

•Alternative for psr file name you can use beas form names beas form names

•Some windows support different parameters

command
Sends command to child window

Placeholder are converted in the target-Window

Special commands:

new     For new entry (set str_parm.b_parm to "true")

del     Send the del-Command via Post-Post

Example:

command=post=messagebox=hello world

 

If you want to open a form with full access for users that do not have access, you can define

command=access=full

This overwrites all other access definitions in this window.

argument=<value>
Sets this Argument in the target window

In the target window you can check the arguments (Variables) in the MASTER-Script with the command: argument.

Variable-Name: use for the first letter: a ( = Argument)

Second letter is the Datatype

Example:

al_docentry = Argument, Long

as_doctype = Argument, String

This is only for Info.

modal=true

Only child window:

Wait for Closing the Child-Window

 

Open own custom forms

You can create and open own, custom forms easily with the object ue_form

 

If you need complex windows with many functionalities, you can use PowerBuilder to create your own PSR files, which you can save in the project folder. For opening PSR files from the project folder you don't need to define the folder. The PSR-File name is enough.

 

Overwrite Standard windows

You can overwrite standard windows if you save the window with same name in the project folder.

But you lose any compatibility to the default functionality. Use this only if you want to replace the default functionality completely.

 

PowerBuilder Version for creating own forms:

You need same Powerbuilder Version or a preview PowerBuilder version.

 

Beas 9.3: Powerbuilder 2017

Beas 2020: Powerbuilder 2019
Compatibility: Comma delimiter, new and newedit

The commands "edit" and "newedit" are obsolete. Better use "openwindow" and "opennewwindow".

openwindow=[DataWindowname/beas form name]=[str_parm:pass-on value,str_parm:pass-on value]=[pass-on command°pass-on command]

 

Commands can be nested.

The window gets the complete istr_parm and you can change the values when you call the window.

 

Example:

openwindow=beas_ItemMasterData_Edit=s_parm1:<itemcode>=befehl=del

The article-edit window opens and the commant "DEL" is fired via Postevent.

 

openwindow=beas_WorkOrderPos_Edit=belnr_id:<belnr_id>,belpos_id:<belpos_id>,belpos2_id:<belpos2_id>

opens the production window with arguments.

 

For declaring variables in the target-window do not use the str_parm-parameter, but declare the variable with the prefix "var."

openwindow=beas_WorkOrderPos_Edit=var.my_order:<belnr_id>

In this example you can work with the variable "my_order".
