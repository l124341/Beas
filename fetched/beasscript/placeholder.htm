Contents

you can insert placeholders to header and footer between  <...>

These are the placeholders:

 

source_header

header of document. All fields, e. g. ORDR for order. Attention: When previewing (as soon as this function is available) not all fields are filled.

source_line

Document-Lines all Fields, example Order all Fields e.c. from rdr1 or inv1

document_header

All fields from beas_document_header

document_line

All fields from beas_document_line

companyinfo

Special fields from oadm (Company):
syscurrncy,maincurncy,compnyname,compnyaddr,printheadr,phone1,phone2,fax,e_mail,freezoneno,taxidnum,revoffice,cmpnyaddrf,printhdrf,phone1f,phone2f,faxf,manager,managerf,taxidnum2,taxidnum3

contactadr

All fields from OCPR (Ansprechpartner)

owneradr

Special fields from Personal (ohem):
firstname,middlename,lastname,jobtitle,position,dept,branch,officetel,mobile,pager,fax,email

invoiceadr

invoice address
cardcode,cardname,address2,address3,street,block,zipcode,city,state,country,countryname,phone1,fax,email

shipadr

shipping address. All fields from OCRD

payment

all Fields from Payment OCTG

skonto

Discount-Table ocdc: code and tabledesc

 

Example

My Address: <companyinfo.compnyaddr>
