printer


Contents

tools=printer=xxx

 

additional printer-function

 

tools=printer=set=<printername>

sets the current Printer for printout formula sybase powerbuilder datawindows (psr-file)

Example:

printer.set=<printer>

print

 

tools=printer=default=<printername>

sets the <printername> to the defaut printer (only for printout datawindow psr-files)

tools=printer=set=<printername>

sets the printer to default printer (only for printout datawidnow psr-files and pushes the current printer in variable "defaultprinter"

// print the current formular on hpoffice

// and after print return to the default printer

tools=printer=set=hpoffice

print

tools=printer=set=<defaultprinter>

tools=printer=get

gets the current printer name and set the variable "e_printer" with the printer name

tools=getdriversport=<printername>

gets driver and port from the printer in variables

value_printername, value_printerdriver, value_printerport

 

Example:

tools=printer=getdriversport=hpoffice

printobject=selectprinter=<value_printerdriver>=<value_printername>=<value_printerport>

getdriverstodropdown

sets drop-down values for all printers in variable "value"

in this way you can create a printer-dropdown-field

 

Example:

You have a column for choose a printer with name "printername"

 

tools=printer=getdriverstodropdown

setvar=dropdown:printername=<value>
