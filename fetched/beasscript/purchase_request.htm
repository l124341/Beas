purchase request


Contents

This object creates a Beas purchase request.

 

object=ue_mrp=purchase_request=propertie=value<tab>propertie=value...

object=ue_mrp=purchase_request=itemcode=po_batman

Example:

object=ue_mrp=purchase_request=&

 cardcode=S1000<tab>&

 itemcode=A1004<tab>&

 quantity=20

 

Properties

typ

P=Purchase order (Standard)
W=Work order

cardcode

itemcode

znr

version

quantity

quantity in purchase unit, default = 1

width, height, length

project

whscode

target Warehouse, default = default warehouse from item

deliverydate

Date of delivery, Default=today

info

price

the price

if you don't set this, beas use standard price

currency

date

document date, default=today

basetype

Id from SAP or "wo" for work order

basedocnum

SAP DocNum

basedocentry

SAP DocEntry

belnr_id

Work order Docentry (set basedocnum and basedocentry)

baseline, belpos_id

base line or belpos_id

baseline2, pos_id

the pos_id (bom position)
