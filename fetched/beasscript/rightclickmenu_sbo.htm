rightclickmenu (SBO)


Contents

insert an entry in the right-click-Menu in SAP-Forms

beasgui=rightclickmenu=type=caption=uid=[image=[position=[enabled=[checked=[command, if not windowevent...]]]]]

 

only for sap-Forms

you can call this function only in windowevent prerightclick

 

 

Property

Description

type

1 = normal entry

caption

the text-Message in the Menu. example: <translate:My Menu Entry>

uid

Identification (objectname)

image

Picture with full link, example

<global:system_home>bmp\project_red.png

position

Position in the Menulist

enabled

boolean - set enable/disable, example true, false

checked

boolean, set check-Propertie

command

set Command directly

but you can also work with windowevent

 

For example see Create_Right_Click_Entry
