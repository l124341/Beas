header function

you can use header function without the routing-base function, example to load and update the header

if you load a routing or create a new routing, the header is loaded/created automatically

 

routing=header=load=<routing-id>

Loads the header. If no header exists, it creates the header

routing==header=update

Updates/saves the routing

routing==header=initall

Creates headers for all BoMs without headers

routing==header=property=value
Sets property in the header

 

Example:

declare=routing==ue_api_routing

routing=getbykey=A001

routing==header=description=my bom

routing==update
