More information

 

Round the value with SAP Price rounding rounding rule

if you do not define the currency in the second parameter, Beas uses the Main Currency.

 

Rounding type: Business rule

Example with 2 decimal places:

0.123 -> 0.120
0.125 -> 0.13

 

If you set the currency in the format string, beas check, if you have a special rule in the currency setup.

 

Beas supports only the setting in column "Decimal", but not the rounding definition in "Rounding"

 

If not, Beas uses the default price rounding, which you can set in General settings > display > Prices:

 

beas 9.2 PL: 05
