setreservation


Contents

creates reservation- or issue-list for a Workorder

 

object=ue_reservation=setreservation=propertie=value [tab] propertie=value [tab] ..

 

or

declare=ue_reservation=res

res=property=...<tab>property=...

destroy=res

 

 

Property

Property

Description

filter

sets the Filter, example: beas_ftstl.belnr_id=100 and beas_ftstl.belpos_id=20

you have the table beas_fthaupt, beas_ftpos and beas_ftstl

only target is Work order

whscode

uses this warehouse for reservation. If you set this, this warehouse has a higher priority as all other rules

only target is Work order

stagearea=[whscode]

the stage area for Receipt. This Warehouse has a higher prioirty as whscode or all other rules


quantity

Quantity for Receipt. With this value the object calculate the issue-quantity. If you don't set the quantity, the object calculates the full issue-quantity

only target is Work order.

scrap

Scrap for receipt

retro

activate the backflushing-system. Creates list only for the Afo-Position (afo_id). You must set the docentry, linenum and afo_id-Property

only target is Work order

afo

Current Afo. Only needed, if you use retro=true

only target is Work order

docentry (or belnr_id)

the belnr_id. If you set this, the Filter is set to this document

only target is Work order

linenum (or belpos_id)

the belpos_id.  if you set this, the filter is set to this position.

only target is Work order
