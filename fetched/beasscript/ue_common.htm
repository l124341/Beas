ue_common


Contents

 

Object to read/write the common-interface

 

declare=ue_common=scommon

scommon=<function>

 

timer=1=scommon=readlocallines

 

readlines

reads all lines

readlocallines

reads only lines for local iD

(for background-procress, allways in the system-window)

read only, if instance-Variable "sys_background-read" not false

if you send a command with sendlocal or sendbackground, beas set the

Variable to "true"

readlocallines set this to "false", if the stack is empty

sendlocal=script

sends a script for this station

sendbackground=script

sends a script for this station - execute in the background (only 1 task / step)

setid=<session>

sets Session-Name, if not stationname

 

Work with background-Process

 

if you send a command with sendlocal or sendbackground, Beas starts in the system-Window a background-process and executes this all 1 second

if the stack is empty, Beas deactivates the background-process

 

 

for ll_loop=1 to 3

 object=ue_common=sendbackground=messagebox=info$hello loop : <ll_loop> {no check}
