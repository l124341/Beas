ue_windowsetup


Contents

With this window you can retrieve window information, can modify a window and can change properties

Beas uses this for the Customization function.

gettabobjects

 

x
sets values for the drop-down field with all existing tab sheets of the current data window

 

sets drop-down in the target field with all existing ue_tab objects from edit window

 

Example: we fill field etabs in datawindow dw_1 with this information

winsetup.gettabobject=dw_1.etabs
