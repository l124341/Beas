Work with xgantt-field

<xgantt.datafield.[id]>

 

 

Example:

xgantt=nodes=<ii_nodeid>=4=2018/6/19

 

Example description:

ii_nodeid: the active node id

4:         specified time "routingstart"

2018/6/19:  Startdate
