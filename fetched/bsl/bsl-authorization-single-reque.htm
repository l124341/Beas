For single request calls (without Login/Logout) follow this process:

Work station settings

1. Define the name of the client in "Work station" and Connection Type="Service"
2. Go to the "WEB" tab and define a Password with good security ("test" is not a good example)

Window system_station_edit.psr

 

NOTE:
Use this only for single requests. If you need many request in short time, the login -> request/request/request -> logout variant is faster.

Attention: The cookie "beas-sessionid" should be empty for the proper behavior of this function.

 

Now you can define stationid and password as Parameter in your URL String:

 

 

NOTE: all properties lowercase. Correct: stationid, wrong: StationId
The system creates a login, executes the request and sends a logout automatically.

 

Supported properties:

stationid = the name defined in work station Settings

password = the defined password in page "WEB"

pers_id = the personnel Id (define this if possible!)
