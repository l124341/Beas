IssueWo


Contents

Creates a manual Work order Issue Document.

Note: GET is not possible. Use Issue/IssueLines.

 

POST

IssueLines

Post Examples

 

HTTP: post new issue document for WO 642, position 10, pos2 = 20

odata4/v1/issue

{
"Transaction":"issuewo",
"DocumentLines":
 [

     "Base_DocEntry":642,

     ]
}
#end
