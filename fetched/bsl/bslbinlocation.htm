Attention: Default locations have higher priority.

 

From the three default bin locations, the priority is set as follows:

Default Bin Location of the Item > Default Bin Location of the Item Group > Default Bin Location of the Warehouse

Therefore, if you have specified a default bin location for the item or item group, the enforced default bin location on the warehouse level is not in effect.
