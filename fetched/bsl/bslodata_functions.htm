Functions


Contents

Note:
Currently a limited number of function calls are supported. Functions are not allowed to be used as parameters.
It is not possible to use function calls inside function calls!

 

The following functions are supported:

Name

Description

concat(any,any[,...)

Allows concatenation of two or more properties.

The properties can be:

•Number

•String

•NULL fields

•Boolean

•Date, DateTime

•"text"

•Numeric information as 1.234

•Placeholder

Functions are not allowed.

 

Example

Item?$select concat(ItemCode," ",IteName," Stock: ",onhand)

 

Note: HANA does not support concatenation of more than 2 strings or combination from different field types. The Beas Service Layer generates SQL HANA syntax automatically, making this possible.

 

Example

With 3 parameters, the system generates the following syntax in the HANA database:

conact(to_alphanum(x),concat(to_alphanum(y),to_alphanum(z))

 

left(field name,number)

Return number characters from the string argument (example: field name) from the left side.

Example

Item("RM")?$select=left(ItemName,5)

right(field name,number)

Return number chars from the string argument (example: field name) from the right side.

Example

Item("RM")?$select=right(ItemName,5)

sum(field name)

Summarize the field. Same as SQL sum()

Note: if you have additional fields, you must work with $groupby.

space(number)

return count of spaces. Use this to create empty fields

Example:

item("RM")?$select ItemCode,space(10) as myUdfField

 

This returns item code and an empty field with the name "myUdfField"

object
return an empty field from type "Object"

 

Use this,  if you want to save JSON object information in this empty field
Different to String field: In String field the JSON result will be saved only in "...JSON...", but this is a string and not JSON.

 

Example:

in resultSet "b" there is a field attribute

and you want to save the result of another entity as json

 

let attrib=bsl.get("ItemBatchAttributes?$select=BatchAttributeCode,Description,Mandatory,InputType&$filter=ItemCode eq :itemCode").toString();

 

b.attributes=attrib.toString();

this returns 

"attributes":"[\"Code\":\"Test\"]";

 
if field is type "object", the result is

"attributes":["Code":"Test"];

 

Example:

 

#jbs
let itemCode="RM_B";
let distNumber="test";
let batchInfo=bsl.get("BatchNumber?$select=Batch,Version,BatchAttribute1,BatchAttribute2,AdmissionDate,ManufacturingDate,\
ExpirationDate,Details,Status,0 as OnHand,space(1) as BinLocation,space(1) as RFID,object() as attributes\
&$filter=ItemCode eq :itemCode  and Batch eq :distNumber");
 
if (batchInfo.rowcount()==0) batchInfo.insertrow(0);
// Save Attributes from this Item in object field "attributes"
batchInfo.attributes=bsl.get("ItemBatchAttributes?$select=BatchAttributeCode,Description,Mandatory,InputType&$filter=ItemCode eq :itemCode").toString();
alert(batchInfo);

boolean(value)

This return a boolean value in the resultSet object

Example:   $select=boolean(false)  

 

In the data store you can see value 0. If you export this to json, it returns false
