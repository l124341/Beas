Examples:

Creates a transfer document  

#define ls_json
{"Transaction":"transfer",
"DocumentLines":

[
  {

    "ItemCode":"RM_B",
    "Quantity":1,
    "WhsCode":"01",

    "ToWareHouse":"02",

    "BatchNumbers":[ { "DistNumber":"111", "Quantity":1 } ]

  }
]
}
 
#end
instance bsl b
b.post=Transfer=<ls_json>
messagebox=<b.ret_code> <b.ret_text> <b.ret_value>
