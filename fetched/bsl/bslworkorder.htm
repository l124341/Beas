Post work order

You can create a work order only with the definition of Work order positions. You can't define Bill of Materials or Routing position, only the BoM/Routing ID.

Example create work order

 

instance bsl b
b.post=Workorder={"WorkorderPos":[{"ItemCode":"FP","Quantity":2}]}
if <b.ret_code> = -1 then
   messagebox=Error create work order : <b.ret_value> 
else
  messagebox=Work order <b.ret_value> created
end if
