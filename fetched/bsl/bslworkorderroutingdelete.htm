Delete a routing position

 

Only possible:

- if no open time stamp exists

- if no time receipt exists on this position

- no linked purchase orders existing (external process)

- work order position is not closed

- work order position is changeable

 

if all OK, the system deletes

- routing position

- linked parallel position

- time reservation, time planing for this routing position

- pool list information

- Links from Bill of Material to this Routing position

- Links from Slave position to this master positions

 

DELETE WorkorderRouting(DocEntry,LineNumber,LineNumber2)

 

return value 1 for OK otherwise an error
