In Beas Service layer you have access to the complete Quality control system of Beas.

 

How the QC System of Beas works

For all details see Beas Help
How to create a QC Order

Beas creates the QC Order automatically based on SAP Documents.

If you create SAP Documents outside the Beas environment, you can use the transaction notification function for create the QC Order.

See Configuration wizard:

 

Additional functions are available, for example to create QC order manually.

GET QCOrder/CreateQcOrder() -> Create non-SAP document related QC Order
GET QCORder/CreateQcORderFromSAPDocument() -> Create SAP document related QC order

For more details see QCOrder.

 

Note: It is not possible to create a QC order with POST Command.
How to change a QC Order

It is possible to change some fields in QC Order or to release it.

This is possible with PUT command and a release is possible with different QCOrder-Functions.

For more details see QC Order
How  to add or change a sample

Add a sample is possible with

GET QCOrder/CreateSample(). See QC Order

To release a sample:

GET QCOrderSamples/Release1()
GET QCOrderSamples/Release2()

or via PUT command. See QCOrderSamples

 

Note: Electronic signature is not supported in the back-end. This must be developed in the Front-end.
How to work with Measurements

It is possible to set value, set OK flag or to release by function or put command

 

Example:

GET QCOrderMeasurement/setValue(1024,1,10,3.4)

 

Change Block Reason to "WrongColor"

put QCOrderMeasurement(1407)   {"BlockageReasonId":"WrongColor"}

 

Note: Electronic signature is not supported in the back-end. This must be developed in the front-end.

It is not possible to create a new measurement positions or to change main measurement definitions.
How to work with Transfer

The BSL delivers the following functions:

- Read all related Items / Batches / Serials / BinCode information with
get QCOrder/TransferLoad()

 

- Return the default target warehouse (example: If you activate "Rejected", you can have another warehouse) with
get QCOrder/TransferGetWareHouse()

 
- Post the transactions (Transfer, Issue, Edit, POReturn with
post QCOrder    
{"transfer":{transfer information}}
Limitations, not supported functions

- 4 eyes concept: Electronic signature is not checked. This is part of the Front end

- QC Attachments are not supported
