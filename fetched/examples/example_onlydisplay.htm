E: Disable editing without lock


Contents

 

You have a field with dropdown and want to disable the manual change. Only dropdown is allowed

For this no beas property is available. But you can change this over DataWindow syntax

 

dw_1.modify=udf1.edit.displayonly=Yes

 

Now dropdown is possible, but manual changes by keyoard is locked.

 

see datawindow column edit
