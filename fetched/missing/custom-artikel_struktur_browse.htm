Item Structure window

artikel_struktur_browse

 

 

Open Window

BeasScript:

by system name:

openform=beas_ItemStructure

by window file name

openwindow=artikel_struktur_browse

 

Parameter:

s_parm1 (or first parameter): filter type: filter / filterfix / item

s_parm2 (or second parameter): the argument for s_parm1

 

Filter type:

filter: Define Start filter, which the user can overwrite with right mouse click on a column title. Filter defined in s_parm2

filterfix: Define  filter, which is not changeable. Filter defined in s_parm2

item: open structure for this item defined in s_parm2

 

Examples:

Open for one item

openform=beas_ItemStructure<tab>item<tab>FP

 

Window information

This is a structure view and display different sources, example item entry, bill of material entry and so on

The type is defined in variable <dw_1.item.zeilentyp.value>
