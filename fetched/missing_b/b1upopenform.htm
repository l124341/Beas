B1UP: open beas form


Contents

 

It is possible to open every Beas form

 

openform(BEAS:[formname]|Parameter|Parameter);

 

You can define the window with Beas-Id or PSR-File name

 
@store1=6002452;
openform(BEAS:ItemHistory|@store1);

 

if you want to delete or create a new entry, define "new" or "delete" as last argument.

 

Createa new Bill of Materials entry for item FP

 

openform(BEAS:BOM_Pos_Edit|FP|new);

 

Delete Position 20 from Bill of Materials FP

 

openform(BEAS:BOM_Pos_Edit|FP|10|del);

 

For the list of main windows see Beas Window Names

For more information on Open forms see Open a window
