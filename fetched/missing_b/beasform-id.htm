Item Master Data

 

beas_ItemMasterData_Structur

optional: item number
Item Structure window

Parameter:

1. Open by
  filter: define own filter in next parameter

  filterfix: define own filter in next parameter, which you can't overwrite in the form

  item:  define in next parameter the item number, which you want to open, expand structure from the item

 

Example:

Open structure from item "FP"

openform=beas_ItemMasterData_Structur|item|FP

 

See Custom Item Structure window
