DI-API: connect_extern


Contents

Connect the di-api to another database.

 

declare=myapi=ue_api_sbo
myapi=connect_extern=db=training<tab>username=manager<tab>password=manager

 

 

companydb (or db, database)

set the database-name. Primary

server

set the server. Default is current server

dbpassword

set the database password. Default is the current password

dbuser

set the database user. Default is the current database-user

username

set SAP-Username. Primary

password

set the SAP-Password. Primary

servertype

Type of SQL-Server as number - see SAP-documentation. Default: current Servertype

1=automatic, 4=sql2005, 6=sql2008
