DI-API: getbusinessobject


Contents

 

create the business object, which you want to retrieve, load or delete

 

d.getbusinessobject=objectId

 

objectId = The SAP Object Id

 

Example:

// Load sales order
setvar=ll_docentry=3000
declare d=ue_api_sbo
// Define object as "SalesOrder"
d.getbusinessobject=oOrders
// now the object "d" is the sales order. 
// in different to other languages it don't return another object
// now you can load or create it
// Load
d.getbykey=<ll_docentry>
// change
// ...
// update
d.update
// at end : destroy
destroy d
