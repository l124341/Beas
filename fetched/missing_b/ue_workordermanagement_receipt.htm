ReceiptLineManualSerialnumber


Contents

This special event is called only in

 

Time receipt over Desktop solution

Work order Backflushing over Desktop solution

Not over WEB application or Work order - collective receipt

Not for negative Bill of Material positions

 

This event is called if you receive an assembly with serial number before Event ReceiptLine is called

In this event you can change the DistNumber of the serial number again.

 

Reason:

In Time receipt and Backflushing process the Batch/Serial number definition is BEFORE the system creates the issue document.

The order is in this case not always correct. In this way you can change it.
