enhanced workordermanagement-system

 

These events are at disposal:

 

strukturinit
Sets variable which should be used for the treeview

 

These variables can be set:

wostlselect

select-command for viewing within a material position

wpafoselect

select-command for viewing within a routing position

 

Information:

It is better to define this directly in window settings in the work order structure window

timerecordingstart
At start from a time recording

 

Variables to read:

e_belnr_id, e_belpos_id,e_pos_id (routing-pos), e_row (from current datastore, internal, is > 1 if you work with master-slave for slave-entrys), e_pers_id

if you return failure, the process is canceled with error message 1100 "Error in timerecordingstart"

timerecordingend
At end of the time recording

 

Variables to read: See timerecordingstart

ojdt_transid: the generated journal entry

ojdt_transid_storno: if Beas creates a cancellation - journal entry, then the ID in ojdt

e_itemstampid: the ID (buchnr_id) in beas_arbzeit
