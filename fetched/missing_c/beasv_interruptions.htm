BEASV_INTERRUPTIONS


Contents

The BEASV_INTERRUPTIONS dashboard view contains all the previous, current and planned interruptions for all resources and tools with their respective start and end date. The view also includes a calculated field called InterruptionDuration, which is the amount of time between the interruption start and end date in hours. This field shows interruption hours in the future if the end date is later than the current date. Therefore, the InterruptionUntilToday column is created in the view, so that it is possible to easily get the interruption hours up until the current date. Other interruption details are included, such as the interruption reason, description, status and operator.
