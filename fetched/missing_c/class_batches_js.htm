class_batches.js


Contents

 

This class is used in all our applications as a common interface to deal with batches, and the modal window is named "Batches: Extended Information"

Allows you to deal with a batch of batches for incoming, outgoing processes or just displays information in read-only mode, applying the necessary rules in each case.

 

 

To include this library in your app, just add this code to your app source code in Beas, between the "_header()" and "_footer()":

<script src="assets21/js/class_serials.js"></script>
