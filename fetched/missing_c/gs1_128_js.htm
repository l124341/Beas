gs1_128.js


Contents

This object decodes a GS1-128 code bar and returns each AI found in the bar code as an associative array.

 

To include this library in your app, just add this code to your app source code in Beas, between the "_header()" and "_footer()":

<script src="assets21/js/gs1_128.js"></script>

Method Detail

Description

decode

decode( bc )

Decode a GS1-128 bar-code and return an associative array with all AI detected and the values for them.

 

Parameters:

{string} bc

The bar code to decode

 

Ex. Ê97rm01bÊ10LOT01234Ê98BWÊ99C-1001Ê3102012345

 

Ê0012345678901234567897rm01bÊ10LOT01234Ê98BWÊ99C-1001Ê3102012345

 

Returns:

{associative array}

 

Example

var res = gs1_128.decode( "Ê97rm01bÊ10LOT01234Ê98BWÊ99C-1001Ê3102012345" );
console.log(res);
 
{10: "LOT01234", 97: "rm01b", 98: "BW", 99: "C-1001", 310: "2012345"}

getdate

getdate( yymmdd )

Format the bar-code date as a date with the format YYYY-MM-DD

 

Parameters:

{string} yymmdd

The bar-code date with the format YYMMDD

 

 

Returns:

{string}

The date with the format YYYY-MM-DD

 

Example

var res = gs1_128.getdate( "770817" );

console.log( res );

 

2077-08-17
