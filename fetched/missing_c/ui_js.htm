columns
columns(columns)

Description

Render a group of columns (responsive).

Parameters

array

Array of json objects with the columns:

[ column1, column2, ...m columnN ]

columnX definition:

ID

(optional) The column ID

size

Size for this column. Available sizes are: 3/4, 2/3, 1/2, 1/3, 1/4, 4/5, 3/5, 2/5, 1/5

content

The column content

Return

string

The HTML to create the columns

Example

> ui.columns( [{size:"1/5",content:"This columns should be 1/5 of the size. (Or all width in a mobile)"},
{size:"3/5",content:"This columns should be 3/5 of the size. (Or all width in a mobile)"},
{size:"1/5", content:"This columns should be 1/5 of the size. (Or all width in a mobile)"}] );

Preview:

In the preview of the example you can see how the above string can modify the size of the columns.
