Load Configuration


Contents

This method load the initial configuration for a configurable item, and the cross references if there are any. After this call you have all the ingredients to render the configuration (see Assembling the configuration).

 

/productConfigurator/exec

POST

Content-type: application/x-www-form-urlencoded

 

beasToken

string

The token to authenticate yourself (leave it empty for now)

action

string

The action to request, in this case must be "load"

Example:
action:"load"

variant

integer

(optional) The configuration's id to load (variant number)

itemcode

string

The configurable item code

cardcode

string

The card code (customer) to use for the prices and discount applicable to the configuration

priceList

number

Price list to apply to the components on this configuration

currency

string

Currency to use (all the configuration will be converted to this currency)

*The exchange rate must be set, otherwise you'll get an error

 

Content-type: application/json

 

title

string

Configuration title (by default is the item code name).

description

string

Configuration description

checkbox_translation

array[2]

Contains the values you must sent for checkboxes unchecked/checked.

 

Example:
checkbox_translation:["No","Yes"]

currency

string

The currency code used.

 

Example:
currency:"EUR"

currency_display

string

The currency string to display.

 

Example:
currency_display:"€"

rows

array

Array of rows, each row has the next properties:

bezeichnung

string

The control title

 

Example:
bezeichnung: "Design"

bild1

string

Image to display together within this control

 

Example:
bild1: "sofa.jpg"

d

integer

It determines where this control has dependencies or not. Possible values are [ 0 | 1 ] only.

A control with dependencies, d:1, means you need to request an update after the user makes any change in this control

 

Example:
d: 0

eingabetyp

string

Type of control to render (valid when the parameter typ:"0" is a selectable control )

D

Drop Down

N

Radio Box

C

Check box

L

Text area

<empty>

Input

 

Example:
eingabetyp: ""

langtext

string

Long description to display

 

Example:
langtext: "This is a long description to display under the control title"                

nr

integer

The ID entry in the table BEAS_OITM_PRODUKTKONFIGURATOR for this definition.

This will be used later to link the parameters/options to

 

Example:
nr: 3

parameter

string

Control's name ID for this row

 

Example:
parameter: "numberOfSeats"

preis1

decimal

Price for this selection

 

Example:
preis1: 1.23

status

string

Status of this control:

2

ERROR

An error in the calculation does not make it possible to continue calculating the right values. The current configuration is useless and you should not continue using it.

1

Incomplete

This error should never be received as it is used internally only.

0

OK

The value of the field was calculated without any further problem.

typ

string

Type of control to render

0

Control is selectable

In combination with eingabetyp you need to render this control as Input, TextArea, Check Box, Radio Box, DropDown.

1

Block

This is the start of a new block and all the rows below this will belong to this block.

2

Info

This row contains  information text only.

3

Title

This row contains the configuration head (title). Despite the fact that one title should be expected only, be aware that more than one title could be present in the configuration.

203

Set Parameter

Parameter used to store intermediate calculation and reused on other places (no need to render this normally).

200

Selection

This sort of rows should appear after the "selectable controls" only, and contain the options for the radio boxes and drop-downs when you are not using cross reference.

verweis

string

Name of the cross reference with the values available for this control. You can look up on dd[<verweis>] to get the values.

 

Example:
verweis: "CR012345678910

visible

integer

Determine if the control should be visible or not. Possible values are [ 0 | 1 ] only.

Consider hiding/displaying all the options linked to this one for blocks, radio boxes and drop-downs.

 

Example:
visible: 1

vorgabe

string

Current value for this control (or possible value in case of radio boxes, and drop-down values)

 

Example:
vorgabe: "3"

object : associative array

Associative array where the keys are the cross references' names, and this contains the arrays of possible values as [key,value].

Due to historical reasons and the way Beas works, the keys could contain extra spaces to fill the total of 50 characters.

 

Example:

}

            POST /productConfigurator/exec
