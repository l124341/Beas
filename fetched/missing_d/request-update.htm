Request Update


Contents

After any change in the configuration, you must send all the changes made to the initial configuration  in a compact form to retrieve an updated configuration of the configurable item.

 

/productConfigurator/exec

POST

Content-type: application/x-www-form-urlencoded

beasToken

string

The token to authenticate yourself (leave it empty for now).

action

string

The action to request, in this case must be "load".

 

Example:
action: "itemchanged"

itemcode

string

The configurable item.

 

Example:
itemcode: "Sofa"

cardcode

string

The business partner to consider special prices and discounts.

 

Example:
cardcode: "JDG"

currency

string

 

The currency code to display.

 

Example:
currency: "EUR"

pricelist

integer

 

The price list to consider for the items used in the calculations.

 

Example:
pricelist: 1

itemchanged_nr

integer

The ID entry in the table BEAS_OITM_PRODUKTKONFIGURATOR for the definition we are updating.

deprecated, no need to send it

 
Example:
itemchanged_nr: 8

rows

string : json

Array of changes made to the initial configuration. All the changes you made to the initial configuration must be included here.

 

Example:
rows: [{"k":17,"v":"SofaClothRed"},{"k":26,"v":"Y"}]

Content-type: application/json

rows

array

Array with all rows updates after the requested selections in a more compact way: An (array[4]) per row. The fields included per row are ID, Value, Parameter, Visible, Status

 

index 0

NR

integer

The ID entry in the table BEAS_OITM_PRODUKTKONFIGURATOR for this definition.

index 1

vorgabe

string

Current value for this control (or possible value in case of radio boxes, and drop-down values)

index 2

price

decimal

Calculated price

index 3

visible

integer

Determine if the control is visible or not. Possible values are [ 0 | 1 ] only.

index 4

status

integer

Status of this control (see status parameter returned by action=load)

 

Example:
"rows":[
[1,"",0,1,0],
[2,"Y",0,1,0],
...
]

dd

object : associative array

Associative array where the keys are the cross references names and this contains the arrays of possible values as [key,value].

This contains updated cross references only - you need to replace the received after the initial load with these ones.

 
Example:
"dd":{
"CR012345678910":[["1","one"],["2","two"],["3","three"],
["4","four"],["5","five"],["6","six"],["7","seven"],["8","eight"],["9","nine"],["10","ten"]],
"CR02":[["Content 01","Descr 01",""],["Content 02","Descr 02",""],["Content 03","Descr 03",""]]
}

price

decimal

Calculated price for this selection.

 

Example:
"price": 76.000000

title

string

Calculated configuration title.

description

string

Calculated configuration description.

For this example, we are requesting the updated configuration for the item "Sofa", where we changed the "line:7 to SofaClothRed" and the "line:26 to Y"

You must merge these new values/status with the initial configuration in order to render the changes for the updated configuration.

 

Request:

              POST /productConfigurator/exec

              Form Data

       currency=EUR&beasToken=&action=itemchanged&itemcode=Sofa&
             cardcode=C50003&pricelist=1&itemchanged_nr=26&
             rows=[{"k":17,"v":"SofaClothRed"},{"k":26,"v":"Y"}]
