Save Configuration


Contents

Saving the configuration will create a new configuration in the table BEAS_CAFT_VARIANTE_KOPF, and return the new entry ID (VARIANTE). 

Using this new entry when create a new SAP document or work order will select this configuration.

 

/productConfigurator/exec

POST

Content-type: application/x-www-form-urlencoded

beasToken

string

The token to authenticate yourself (leave it empty for now).

action

The action to request, in this case must be "load".

 

Example:
action: "itemchanged"

itemcode

string

The configurable item.

 

Example:
itemcode: "Sofa"

cardcode

string

The business partner to consider special prices and discounts.

 

Example:
cardcode: "JDG"

currency

string

The currency code to display.

 

Example:
currency: "EUR"

pricelist

integer

The price list to consider for the items used in the calculations.

 

Example:
pricelist: 1

rows

string : json

Array of changes made to the initial configuration. All the changes you made to the initial configuration must be included here.

 

Example:

rows: [{"k":6,"v":"2"},{"k":17,"v":"SofaClothRed"},{"k":22,"v":"SofaLegSteel"}]

variant

number

You must not send this parameter normally.

Allow to overwrite an existing configuration (check Beas Help to learn more about the rules)

 

Example:
variant: 42

Content-type: application/json

variant

number

The variant number assigned to this configuration.

 

Example:
variant: 42

price

decimal

The total price calculated for this configuration.

 

Example:
price: 1708.197700

title

string

The calculated title for this configuration.

 

Example:
title: "Brief Description With 1 Cushions"

descr

string

The calculated description for this configuration.

 

Example:
descr: "Text Description With 1 Cushions"

Content-type: application/json

error

string

Error message (see Errors).

 

Request:

POST /productConfigurator/exec

              Form Data

      beasToken=&action=save&itemcode=Sofa&cardcode=JDG&pricelist=1&currency=EUR&
      rows=[{"k":6,"v":"2"},{"k":17,"v":"SofaClothRed"},{"k":22,"v":"SofaLegSteel"}]
Response:

JSON

 

{
  "variant":42,
  "price":1708.197700,
  "title":"Brief Description With 1 Cushions",
  "descr":"Text Description With 1 Cushions"
}
